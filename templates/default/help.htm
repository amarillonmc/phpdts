■FAQ 常见问题

下面以FAQ的形式将最基本的游戏概念作简要说明：
问：常磐大逃杀怎么玩？有哪些模式？
答：这是一个网页文字策略生存游戏，用鼠标点击或快捷键下达移动、探索、使用物品、合成与战斗指令即可游玩。
登录账号后，在首页既可以直接进入全服共用的大房间，也可以在首页房间列表中免费创建普通房间，或消耗少量切糕开启玩法迥异的异色房间（卡牌对战、双控生存、多人合作电梯、单人轮回、搜打撤RAID等）与时光重现房间（YELLOWKNIFE、2009、2011、298SP4等）。
初次游玩建议先浏览基础操作，进局体验两三盘遇到疑问再按目录查询（善用浏览器 Ctrl+F 搜索）。
问：怎么移动？怎么捡东西？体力用完了还能动吗？
答：在下拉框（或 Nouveau 界面的地图面板）点选目的地即可移动；点击则在原地搜索。
移动和探索基础消耗15点体力，可能发现物品、遭遇敌人/队友/尸体、触发陷阱或随机事件。发现但暂未拾取的物品或尸体会自动记入视野（默认最多保留3项，移动后清空）。
当体力耗尽但生命值充裕时，继续移动或探索会自动燃烧生命值代偿体力消耗，请留心血线避免涉险暴毙。
问：怎样战斗？杀死对手后怎么拿战利品？
答：移动或探索遭遇其他角色时可能触发战斗。若我方先制发现对手，可选择（或释放战斗技能）或；若被敌方先制则直接进入交战。
将对手生命值削减至0即可将其击杀，随后可从其装备、包裹或金钱中选择一项缴获。连斗阶段前，尸体还会留在原地供后续再次探索拾取（受短暂尸体保护时间限制）。
问：钱和“切糕”分别有什么用？能不能卖东西换钱？
答：局内金钱用于在商店购买武器、补给、药剂、强化材料与路线道具。商店位于「无月之影」「光坂高校」与「花菱商厦」（进入湾城投影后，「中央旧城区」与「下层地下商业街」另设专属黑市）。金钱主要通过击杀NPC/玩家、完成周期任务（QUEST）获得；普通种族无法出售物品，唯有解锁并选用「龙」种族时可通过专属「变现」指令将非任务物品折算为金钱。
「切糕」则是跨局保留的账户货币，可用于在 >>种火商店 购买卡包与机制头衔、在首页创建特殊 RuleSet 房间、在「当前幸存」页面下注或场外赞助快递补给、在「账号资料」中购买天赋点/洗点/定制纸娃娃形象，以及在「幻想世界」投稿原创合成、自定义NPC与地图道具。
问：能组队吗？怎么组队？
答：游戏进入“连斗”阶段前均可组队。创建队伍消耗200点体力，加入队伍消耗100点体力，每支队伍最多容纳10人。
视野良好时队友之间不会互相攻击，遭遇队友可赠送包裹物品（无法直接转交金钱）；但在起雾、浓雾、暴风雪天气或身中「黑暗诅咒」时无法辨识身份，贸然出手可能误伤队友。进入连斗后所有队伍自动解散（部分合作异色模式除外）。
问：生命或体力见底、部位受伤、中毒或中了重度伤势/诅咒怎么办？
答：回复生命与体力可服用补给品（小心有毒补给！）、使用「睡眠」「治疗」指令，或前往「精灵中心」「对天使用作战本部」（及危机四伏的「SCP研究设施」）进行「静养」。
普通部位受伤可点击状态区伤口图标消耗50点体力（黑衣组织35点）包扎；普通属性异常（毒、烧、冻、麻、乱）可服用对应药剂、静养、点击状态图标（特定称号）或消耗1点技能点升级公共技能「治疗」解除。
若在挑战教头等强敌时染上重度伤势（内出血、上下肢破坏等）或诅咒，普通药剂无效！需通过消耗技能点升级「治疗」、持续静养满一定时间（常规180秒，黑衣组织60秒），或使用「强效急救剂」「净灵水」「除厄御守」等专用道具化解。

1.参加游戏

要加入游戏，首先必须注册并登录账号（不同服务器的账号互不通用，可在顶栏切换或查看个人资料）。
登录后可在首页查看当前大房间的运行状态，或通过首页下方的房间面板加入/创建其他模式房间，随后点击。

在加入一局新游戏时，首先会进入入场手续页面，在此可以设置本局参战配置：
1. 头像、性别与宣言：选择心仪的头像（若在「账号资料」中保存并启用了自定义纸娃娃形象，局内也会同步展示），填写口头禅、杀人留言与遗言。
2. 头衔选择：除了展示荣誉外，现版本许多头衔带有入场装备、属性、专属技能或特殊机制（在账号资料与入场下拉框中可查看头衔效果）。
3. 种族选择（大房间与普通房间开放）：默认为「人类」；通过账号天赋树解锁后，可在入场时切换为「兽人」「妖精」「龙」「鱼人」或「ＡＩ」。
4. 内定称号选择：入场提供 9 项固定可选称号（含「无」与八种常规/功能称号）以及每局从特殊池中 随机抽取的 3 项特殊称号。若计划在局内使用商店或头衔赠送的称号卡转入「元素大师」「码语行人」「崩坏心核」「可怜猫」「神骰叛军」等上级社团，请在入场时选择「无」。



确认无误后点击即可正式踏入战场。

本轮为「RAID：暴走笼中鸟」异色模式，不启用常规房间的「最后幸存」「锁定解除」「幻境解离」或核爆路线。
玩家可以击破安全区的战利品容器、将宝物记入个人账本后随时撤离结算积分；也可以前往隐藏区域「代码源流」提交指定材料，寻找并部署三件唯一封印部件，由完成最终部署者的存活未撤离队友共同达成封印胜利。详见 >>房间系统与 RuleSet 模式指南<<。
【模式房间流程说明】：
你当前所在的「{$help_ruleset_name}」采用该 RuleSet 的独立流程与结局判定（不启用大房间的新版四条结局路线）。
若为 YELLOWKNIFE / 莱卡的进击 / 经典历史版本，主线沿用经典「最后幸存」「锁定解除（击败无月之影BOSS取得信物）」与「幻境解离（英灵殿路线）」；若为 FCG / AN:OTHER / 帧间电梯 / 闪回，请直接参阅 >>23. 房间系统与 RuleSet 模式指南<<。以下展示当前大房间的基准路线：

【常规生存胜利】：
◆ 最后幸存：淘汰战场上其余所有参战者，成为最后独存的一人（若场上存在「ＡＩ」种族玩家，其待机分体不重复计入存活账号数；若有人正处于隐藏的「湾城投影」中，则需待湾城内决出结果或超时消散后方会结算最后幸存）。

【当前大房间·四条主线结局路线】：
除了残酷的厮杀求生外，当前大房间（及普通房间）围绕「锁定解除」与「幻境解离」设有四条难度与叙事层次各异的破局路线：

① 伪·锁定解除（常规解禁）：
合成或寻找「移动PC」临时解封禁区 → 前往无月之影击败坐镇 BOSS 红暮，拾取「挑战者之印」 → 使用后召唤三位朱鹮执行官（HOROU、ORIHIME、SAYA），寻找并击败他们收集三张「社员专用的ID卡」（也可挑战虚空中的其他隐藏强敌） → 合成「游戏解除钥匙」并使用，带领剩余参战者脱离战场。
※小贴士：探索「指挥中心」时有概率偶遇某位神秘锻冶匠，免费试用一次不稳定的「便携式化身平台」，暂时借用朱鹮执行官的机体与战技。

② 真·锁定解除「冰炎合璧」：
击败无月之影的红暮拾取「红杀教头挑战状」 → 使用挑战状向全图发起试炼，迎战并全灭八位新红杀教头（铁城、灵翼、破石、银锤、电反、三步、白凰、绯刹） → 八位教头全数退场后，认真应战的参战者 红暮（受创后会游走撤往安全区）与蓝凝（驻守无月之影布设光球雷场）将联袂现身 → 同时击败二人取得冰与炎两枚钥匙，合璧为真正的「游戏解除钥匙」达成真·解禁！

③ 伪·幻境解离「沙盘一梦」：
在商店购买或全图探索拾取「【动物团的七封请柬】」并使用，激活不占普通任务栏的七项公共事件「七日送行」（QD1～QD7） → 前往第 34 号区域「代码洪流」点击「进入动物大排档」与七位动物团成员交谈、领取专用工具或重置未满意的事件 → 完成全部七项送行且其中达成 4～6 项「温柔送行」后，在大排档领取「【湾城通票】」。
使用通票后将卸下并清空外部随身装备与背包（保留金钱、等级、属性、六系熟练与已学技能，发放适配最高熟练度的旧红杀成长武装与应急物资），踏入限时 75 分钟、无禁区但超时即消散的隐藏地图组「湾城投影」（中央旧城区与「下层」地下商业街开放专属黑市） → 在寂山书院击败演习守卫善德、恶德（可先击破散落街区的动物团投影以剥夺善恶德继承的对应技能；交战中主动逃脱亦可喘息恢复并消减减益），将善恶双印合成为「【解离凭证·幻境】」并使用即可通关。

④ 真·幻境解离「真实解离」（最高难度）：
在「七日送行」中达成全部 7 项「温柔送行」后使用「【湾城通票】」 → 踏入强制锁定「模式ＥＸ」视界（双方战斗最终伤害×1.5，无法切换视界）的真实湾城投影 → 在 75 分钟时空锚定时限内（快速突破第一阶段可获得加时），依次跨越「历史残响连战」（附带将攻防熟练与装备词条压回旧日上限、暂时挂起现代社团技能的「时光锚定」）、「旧红杀八大教头」与坐镇终局的两位守望者 → 集齐双钥合成「【解离凭证·真实】」，亲手剥离幻境深处的真实。

3.禁区和连斗

常磐大逃杀标准战场共有 35 个表侧区域（编号 0～34，其中 0 号「无月之影」为初始禁区，34 号现为「代码洪流」）。
每隔一定时间（可在「进行状况」页面查看下一次禁区时间及未来 3 次禁区预告），就会有若干区域变为禁区。
在当前大房间默认配置下，连斗阶段前滞留禁区的存活角色会在禁区增加时自动撤离至安全区；但在部分历史 RuleSet（如 2011、298SP4 等）中，若未切换为「重视躲避」策略滞留禁区，将会被直接抹杀！此外，表侧战场若连续 20 分钟未行动，也会触发反挂机惩罚身亡。

若取得电脑设备「移动PC」，玩家可以入侵控制系统临时解除当前禁区（直至下一次增加禁区为止），从而前往无月之影挑战 BOSS 或搜寻物资。

当禁区增加到一定轮数，或场内死亡的玩家与NPC总数超过连斗阈值（当前基础阈值为 $deathlimit 人并随激活人数动态上浮，可在首页查看），游戏即进入「连斗阶段」。
进入连斗后：停止新玩家激活入场、场上现有尸体全部清除且击杀不再留尸、所有队伍强制解散、任何姿态策略均无法再躲避禁区！若全部表侧区域均变为禁区且无人位于湾城投影内，剩余人员将全部死亡，本局无人获胜。

此外，在游戏停止激活（1禁）或进入连斗后，击败二阶段钥匙召唤的杏仁豆腐并使用其掉落的「杏仁豆腐的ID卡」，可使战场进入「死斗模式」——全场所有NPC立即退场，剩余玩家将直接展开最终决战。
※注：踏入隐藏地图组「湾城投影」的玩家不受表侧禁区与反挂机影响，改为独立计算 75 分钟时空锚定倒计时。


4.游戏界面与副面板

游戏目前提供两套界面风格：原汁原味的经典界面（Default）与支持自由拖拽多窗口的暗色终端Nouveau 界面（可在「账号资料」中随时切换，经典界面页底与 Nouveau 顶栏均支持自定义字体与主题配色）。

画面顶端的导航栏功能如下：
『首页』 返回大厅，可登录登出、查看对局时间与人数，或创建/切换/加入各类 RuleSet 房间。
『站内信箱』 查收系统通知、激活码兑换附件、成就与活动发放的账户奖励。
『账号资料』 查看个人战绩、成就与每日挑战进度；点击编辑可修改头像、宣言、头衔、切换界面、定制纸娃娃形象、兑换激活码以及配置账户天赋树。
『进入游戏』 进入或刷新当前所在房间的游戏主画面。
『战场地图』 查看 35 个表侧地区的坐标分布与当前禁区标示。
『进行状况』 查看实时战况播报、最新聊天记录以及禁区解封状态与未来 3 轮禁区预告。
『当前幸存』 查看存活参战者排行，并可使用切糕进行获胜下注（0禁且未连斗时）或购买商店物资召唤快递员场外派送。
『历史优胜』 / 『玩家排行』 查阅历局优胜记录、终局战报及全服积分/胜率/切糕排行榜。

6.战斗说明

移动或探索遭遇敌人时，主动行动方即为战斗发起方。基础先制概率与天气、基础姿态、隐蔽/先攻修正及技能有关。
若你获得先制攻击，可向对手喊话并选择（或发动已解锁的【战斗技】/【开幕技】）或（先制逃跑必定成功，除非处于特定追击/锁缚机制下）。
若选择攻击，结算完我方伤害后，存活且射程允许、未陷入眩晕等限制的敌人将按反击率发起反击；若被敌方先制，则直接承受敌方先手攻击而无法提前逃跑。
下方为先制遇敌时的经典战斗界面：

怒气与必杀/战技：交战受击、特定装备属性（如重击辅助）或补给可积累怒气（上限 255），用于在战斗中释放强力称号战斗技或重击。
护盾机制：部分称号技能（如锡安成员「护盾」、晶莹剔透「晶璧」）、歌曲（如《水手》）、头衔战技（如「饼来」临时生命护盾）或饰品（如按次数归零伤害的「数据护盾」类饰品、白凰「护符」）可提供护盾。常规技能护盾可抵消伤害，且存在期间免受高额伤害反噬与属性异常。
反噬伤害：当单次打出的伤害过高（超过一定阈值）而自身未装备「HP制御」属性或无护盾保护时，攻击者自身也可能承受武器反噬伤害！


7.熟练度

武器的命中率、连击段数与最终伤害同对应系别的「熟练度」（殴、斩、射、投、爆、灵六系）密切相关。
刚入场时熟练度较低，伤害十分有限；随着不断出击积累熟练度（无论攻击命中与否均可增长，逃跑不增加），中后期同把武器也能打出毁天灭地的输出。
此外，合成物品与埋设陷阱可额外提升爆系熟练度；阅读各系技能书籍（过高时效果衰减）、开启福袋/任务奖励、投入局外天赋节点，或以极低概率在注射「装有H173的注射器」时觉醒L5状态，也能令熟练度大幅跃升。

15.毒药、陷阱与机关

「陷阱」使用后在当前区域埋设地雷并获得经验与爆熟；未触发的陷阱可被他人拾取回收。自己埋设的陷阱与下毒的食物同样可能误伤自己。

26.单机版安装指南

常磐大逃杀（PHPDTS）是开源网页游戏，你可以在 GitHub 仓库 下载最新源代码。
如需在本地搭建单机或测试环境：
1. 环境要求：推荐使用 PHP 7.4 ～ 8.1（仓库内置 Dockerfile 基于 PHP 8.1 FPM + MariaDB，也可直接使用 Docker Compose 启动），Web 服务器（Apache / Nginx / PHP 内置开发服务器）及 MySQL / MariaDB 数据库。
2. 启用短标签与数据库扩展：由于部分历史资源与模板使用 PHP 短标签，请在 php.ini 中开启 short_open_tag = On（或命令行加 -d short_open_tag=1），并确保启用 mysqli 扩展。
3. 通过安装向导初始化：创建好空的 MySQL 数据库后，启动站点（例如在仓库根目录执行 php -d short_open_tag=1 -S localhost:8080 -t .），在浏览器访问 install.php 跟随安装向导填写数据库连接与管理员账号信息——向导会自动导入 ./install/bra.sql 初始化数据表并生成配置文件。
4. 手动配置提示：若参考 config.inc.php.sample 手动配置 config.inc.php，请注意将旧示例中的数据库驱动改为当前 PHP 环境支持的驱动（如 mysqli），切勿在 PHP 7.4/8.x 下沿用已废弃的旧 mysql 驱动。安装完成后用设定的管理员同名账号注册登录即可进入「游戏管理」后台开启新局。
