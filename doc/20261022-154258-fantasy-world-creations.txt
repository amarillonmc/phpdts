幻想世界后续：幻影造物、万象投影

玩家体验
- 默认界面“幻想世界”的两个占位入口替换为“幻影造物”（定制NPC）和“万象投影”（地图物品），Nouveau 同步补入口。
- NPC 可命名，选择五档战斗数值，分别设定六个装备部位的名称、等级及武器种类。保存时生成并固定装备属性，可逐件付费重掷。可购买最多六槽额外背包掉落，自定名称、种类、效果、耐久和属性。
- 地图物品可设定名称、种类、效果、耐久、数量、额外属性与投放地点；每份已采纳投稿每局开局投放一次，随机地点按每件分别抽取。
- 保存前可试算费用；修改按各项增加值补费，减少或移除不退费、不抵扣其他项目。改名保留装备随机结果；改装备等级或种类另收重掷费，避免免费反复刷属性。
- 保存、修改、重掷后均等待审核；拒绝不退款，可以修改后再提交。采纳后进入后续大房间，不修改当局已生成的内容。私人房间不投放。

默认数值与后台
- 五档NPC价格：200 / 400 / 800 / 1600 / 3200 切糕，对应战斗等级10 / 25 / 50 / 75 / 100；完整生命、体力、攻防、熟练和金钱在页面表格展示。
- 五档装备每部位价格：20 / 60 / 150 / 400 / 1000，效果30 / 80 / 200 / 500 / 1000，耐久30 / 60 / 120 / 240 / 500；属性数0 / 1 / 2 / 3 / 4，高档加入稀有属性池。
- 重掷费：装备档位×20；结果可能重复。普通装备无随机属性，不提供重掷。
- 地图物品每件基础200，NPC背包每槽基础100；效果从1起每点加1，耐久从1起每点加2，每个属性加100。地图物品单价再乘数量（1～100）。耐久0表示无限，按65535×2再加2000计价。
- 种类、属性沿用幻想世界普通玩家的选择范围；物品名按实际字段限制30字，NPC名40字；特殊分隔符、HTML、引号等不接受。
- 游戏管理→幻想世界审核（5级或站长）：分别查看待审、采纳、拒绝列表，查看完整属性、写审核说明、退回已采纳内容，并设置每局NPC数。
- 默认每局随机投放3名已采纳NPC，同局不重复；池不足则全部投放，0可暂停。价格、档位和数量在 gamedata/cache/vncreation_1.php，后台只改数量。

实现位置与部署
- vn_create.php、include/vnworld/vncreation.func.php：投稿、计价、持久随机结果、扣费及投放；include/admin/vncreation.php：审核入口。
- 沿用 rs_game() 的NPC和地图物品初始化，NPC使用未占用的type=95。装备、六个背包槽及物品para完整写入原生字段，后续战斗、拾取和尸体处理沿用现有逻辑。
- 新增公共 vncreation 表保存跨局投稿及审核池；当前玩家/地图表会在开局重建，原有 vnmixitem 的配方字段也无法保存NPC装备与随机结果，所以不能复用这些表。首次使用自动 CREATE TABLE IF NOT EXISTS，安装SQL也已补齐，无需重装或清空资源。
- 用现有 gamevars 的 vncreation_items 标记避免重复执行开局物品投放；新局原有初始化会清空它。
- 表单使用一次性会话令牌及内容摘要，防重复扣费、越权及以旧审核表单放行已改内容。保存、扣费和审核在数据库表锁内重读状态；保存失败补回扣款。PDO驱动补齐SILENT返回失败的行为，mysqli异常也进入退款分支。
- 需要数据库CREATE TABLE、LOCK TABLES权限、可写的PHP会话存储目录；修改NPC数量还需要当前数量配置文件可写。MyISAM多语句补偿不等于断电恢复事务。
- 大房间仍按其实际RuleSet加载地图及已有随机化钩子。AN:OTHER使用独立角色、物品、合成目录，本次在该模式的配置中禁用原生投稿和投放，保留已有投稿；没有将此功能强行接入其独立玩法。
