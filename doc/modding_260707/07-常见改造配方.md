# 07 - 常见改造配方

本章用“我要做某件事”的方式写。每个配方都先给最小路线，再说明什么时候需要补逻辑。

## 配方 1：新增一个地图掉落的普通恢复品

目标：开局随机地图刷 3 个“测试面包”，回复 HP 80。

改：

```text
gamedata/cache/mapitem_1.php
```

新增一行：

```text
0,99,3,测试面包,HH,80,1,,
```

测试：

1. `php -l gamedata/cache/mapitem_1.php` 对这种文本资源意义有限，但可以确认没有破坏第一行 PHP 包装。
2. 新开一局。
3. 搜索地图，或查数据库 `mapitem` 表确认刷入。

如果当前房间启用了 RuleSet，要改对应 RuleSet 的 `cache/mapitem_1.php`。

## 配方 2：新增商店商品

目标：商店分类 1 出售“测试面包”，库存 5，价格 80。

改：

```text
gamedata/cache/shopitem_1.php
```

新增：

```text
1,5,80,0,测试面包,HH,80,1,,
```

如果商品不显示，检查：

- 当前地点是否是商店地点。
- 分类 `kind=1` 是否存在。
- `area` 是否已经解锁。
- `num` 和 `price` 是否大于 0。
- 当前是否在 RuleSet 房间。

## 配方 3：新增普通合成公式

目标：矿泉水 + 面包 = 简易套餐。

改：

```text
gamedata/cache/mixitem_1.php
```

在 `$mixinfo` 里加：

```php
array(
    'class' => 'food',
    'stuff' => array('矿泉水', '面包'),
    'result' => array('简易套餐', 'HB', 80, 1, ''),
),
```

注意：

- `stuff` 按道具名匹配。
- 结果数组第 4 位是 `itmsk`，第 5 位才是 `itmpara`。
- 不要忘记逗号。

## 配方 4：新增一个普通 NPC

目标：刷 1 个拿刀的测试 NPC。

改：

```text
gamedata/cache/npc_1.php
```

示例：

```php
$npcinfo[90] = array(
    'mode' => 8,
    'num' => 1,
    'name' => '测试 NPC',
    'gd' => 'm',
    'pls' => 99,
    'mhp' => 500,
    'hp' => 500,
    'msp' => 200,
    'sp' => 200,
    'att' => 80,
    'def' => 80,
    'wep' => '测试长刀',
    'wepk' => 'WK',
    'wepe' => 120,
    'weps' => 30,
    'club' => 1,
);
```

测试要新开一局，因为 NPC 通常在游戏初始化阶段写入数据库。

如果要让它只在灵子视界遇见：

```php
'horizon' => 1,
```

玩家也要切到同一视界才能搜到。

## 配方 5：让 NPC 拥有已有社团技能

在 NPC 配置里加：

```php
'clubskill' => array('s_hp', 's_ad'),
'clubskillpara' => array(
    's_hp' => array('lvl' => 1),
    's_ad' => array('lvl' => 1),
),
```

技能参数具体键要看已有技能怎么写。不同技能不一定都用 `lvl`。

## 配方 6：新增一个特殊使用道具

目标：使用“测试徽章”获得 100 金钱。

资源层先让道具能出现，例如 `mapitem_1.php`：

```text
0,99,1,测试徽章,Y,1,1,,
```

然后写逻辑。先找 `include/game/item.main.php` 如何分发 `Y` / `Z` 特殊道具，再选择合适的处理文件。简单测试道具可以放在类似：

```text
include/game/item.special_effect.php
```

伪例：

```php
if ($itm == '测试徽章') {
    $money += 100;
    $log .= '你使用了测试徽章，获得了 100 元。<br>';
    itemreduce('itm' . $itmn);
    return;
}
```

真实代码要看当前函数里变量名和参数结构。重点是：只把 `itmk` 写成 `Y` 不会自动产生效果。

## 配方 7：新增背包

目标：新增一个 8 格背包道具。

资源示例：

```text
0,99,1,轻便背包,A,8,8,^,
```

关键是 `itmsk` 里有 `^`。当前容量通常取 `itme` 和 `itms` 较小值。

测试：

1. 拾取背包。
2. 装备或让系统识别该背包。
3. 尝试把普通道具收入背包。
4. 测试丢弃背包时背包内道具是否掉落。

不要去找“等级影响背包容量”的公式，当前不是那套机制。

## 配方 8：新增社团

目标：新增 `23 => 测试社`。

改显示名：

```text
gamedata/cache/resources_1.php
```

```php
23 => '测试社',
```

改技能列表：

```text
gamedata/cache/clubskills_1.php
```

```php
23 => Array('s_hp', 'test_skill'),
```

让玩家能选：

```text
include/game/clubslct.func.php
```

把 `23` 加进对应选择池。

如需基础属性奖励，在 `updateskill()` 里加分支。

## 配方 9：新增一个配置型头衔

目标：新增头衔“测试者”，只显示，无入场奖励。

改：

```text
gamedata/cache/titles_1.php
```

```php
$titles_list[130] = '测试者';

$title_desc[130] = Array(
    'class' => 'lime',
    'title' => '测试用头衔',
);
```

然后必须给获取途径。例如在某个逻辑里：

```php
get_title('测试者', $name);
```

只加配置不会自动发放。

## 配方 10：新增一个带入场奖励的头衔

目标：“测试者”入场给 50 金钱和一个面包。

在 `$title_valid` 加：

```php
130 => Array(
    'money' => '[:+=:]50',
    'itm6' => '测试面包',
    'itmk6' => 'HH',
    'itme6' => 80,
    'itms6' => 1,
    'itmsk6' => '',
),
```

注意：

- 物品字段要写完整。
- 如果 `itm6` 已被别的奖励占用，会被覆盖。
- 入场奖励只在玩家用该头衔进入游戏时应用。

## 配方 11：新增成就并给头衔

最小步骤：

1. `titles_1.php` 加头衔。
2. `achievement_1.php` 加成就配置。
3. 在对应逻辑处调用完成函数。

例如某个道具使用时完成：

```php
done_achievement_rev(150, 1, $name);
```

如果成就有多阶段，先看同类 `check_*_achievement_rev()` 怎么更新计数和判断阶段。

## 配方 12：新增线性剧情对话

改：

```text
gamedata/cache/dialogue_1.php
```

加：

```php
$dialogues['test_dialogue'] = Array(
    0 => Array('旁白', '这是一段测试剧情。'),
    1 => Array('旁白', '剧情结束。'),
);
```

触发时写：

```php
$clbpara['dialogue'] = 'test_dialogue';
```

如果要不可跳过：

```php
$clbpara['noskip_dialogue'] = 1;
```

如果要选项改变游戏状态，需要在 `command.php` 或其他逻辑中读取选择结果并处理。

## 配方 13：新增隐藏地点

步骤：

1. 在 `resources_1.php` 的 `$hplsinfo` 加隐藏地点。
2. 做入口逻辑。
3. 做出口逻辑，或让隐藏地点组内能移动到出口。

示例配置思路：

```php
$hplsinfo[260] = Array(
    'name' => '测试密室',
    'pgroup' => 'test_room',
);
```

入口逻辑伪例：

```php
$pls = 260;
$pgroup = 'test_room';
$log .= '你进入了测试密室。<br>';
```

只加 `$hplsinfo`，玩家不会自动进去。

## 配方 14：新增结局

步骤：

1. `resources_1.php` 的 `$gwin` 加编号。
2. 找触发点调用 `gameover()`。
3. 改结局模板或 RuleSet story。
4. 补新闻和成就。

触发伪例：

```php
gameover($now, 'end8', $name);
```

需要确认 `gameover()` 当前对 `endN` 的解析能否正确拿到你的编号。编号超过单字符时要小心，因为现有实现用 `substr($mode, 3, 1)` 取结局号。

## 配方 15：新增资源型 RuleSet

步骤：

1. 在 `gamedata/ruleset/ruleset_config.php` 登记规则集。
2. 建目录 `gamedata/ruleset/MY_RULESET/cache/`。
3. 复制最少必要资源文件，例如 `resources_1.php`。
4. 新建房间选择该 RuleSet。
5. 确认 `config()` 实际读到了 RuleSet 资源。

建议先做“只改资源”的 RuleSet。等资源覆盖跑通后，再考虑 PHP 函数覆盖。

## 配方 16：新增特殊机制 NPC

推荐步骤：

1. 先在 `npc_1.php` 里做普通版本。
2. 给它 `type` 或 `clbpara` 标记。
3. 判断机制触发时机。
4. 在对应 hook 写最小逻辑。

例子：死亡时完成任务，优先看 `quest_handle_npc_death()`。

例子：命中后追加伤害，优先看 `revcombat_extra.func.php` 或 `revattr.func.php`。

例子：搜索时触发剧情，优先看 `search.func.php` 的发现流程。

不要把所有特殊机制都塞到一个大函数里。这个项目已经很依赖全局变量，改动范围越小越好排查。
