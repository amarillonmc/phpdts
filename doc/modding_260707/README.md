# PHPDTS 改造说明书

这是一套面向“对 PHPDTS 甚至 PHP 本身都不熟”的改造文档。它不是框架式 API 手册，而是从实际改造者会遇到的问题出发，解释这个项目怎样启动、怎样读代码、怎样改资源、怎样加玩法、哪里需要写逻辑、哪里只改配置就够。

旧目录 `doc/nouveau_250609/` 中的文档仍保留作历史资料，但这套文档以当前源码为准，修正了旧文档里一些过度概括或与实现不符的说法。例如：视界系统不是传统视野/雾区系统，背包容量也不是按等级或装备套公式计算。

## 这个项目的改造分层

PHPDTS 不是现代框架项目。更准确地说，它是一个以全局变量、配置文件、函数库和模板编译器拼出来的网页游戏。

可以按这几层理解：

| 层级 | 主要目录 | 适合做什么 |
| --- | --- | --- |
| 资源层 | `gamedata/cache/`、`gamedata/ruleset/*/cache/` | 改地图物品、商店、NPC、合成、称号、成就文案、剧情文本 |
| 逻辑层 | `include/game/`、`include/*.func.php` | 改物品效果、战斗机制、技能效果、任务判断、特殊 NPC 行为 |
| 界面层 | `templates/default/`、`templates/nouveau/` | 改按钮、面板、展示方式、模板文案 |
| 数据层 | `gamedata/sql/` | 改数据库字段和初始化结构 |
| 房间/规则集层 | `gamedata/ruleset/`、`include/ruleset_override.func.php` | 做一套资源覆盖、剧情覆盖或规则变体 |

很多改造只需要资源层；一旦你希望“玩家点击后发生一段新逻辑”、“NPC 在战斗时有特殊规则”、“任务有新的完成条件”，就必须进入逻辑层。

## 一条最重要的原则

先找已有例子，再改最小范围。

这个项目里很多功能不是通用引擎，而是“某个历史需求的具体实现”。比如任务系统能配置很多字段，但新任务是否能只靠配置完成，要看它是否正好复用已有的 `QuestAction`、NPC 召唤、战斗钩子或物品处理逻辑。照着同类功能抄，比凭想象新增字段可靠得多。
