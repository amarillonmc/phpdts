FCG 轮抽远征经济调整（2026-10-27）

按追加经济 HANDOFF 替换旧的入场费和奖励档位；轮抽、营地、五层战斗规则保持原样。

玩家数值
- 新远征入场费由 500 降为 250 切糕。
- 结算档位（卡组抽 / 升级保底 / 稀有保底 / 结算印花）：
  0 胜：0 / 0 / 0 / 1
  1 胜：1 / 0 / 0 / 1
  2 胜：1 / 1 / 0 / 2
  3 胜：2 / 1 / 0 / 3
  4 胜：3 / 0 / 1 / 4
  5 胜：2 / 1 / 1 / 5
- 先抽稀有保底、再升级保底、最后卡组抽。最终卡组按卡号去重并排除 unlimited 卡，
  已抽中的卡号从后续卡组候选中移除。卡组里的升级稀有卡可用于升级保底。
- 缺少保底候选时，稀有位回退全局稀有池，升级位回退全局非稀有升级池；两者均排除
  能量卡。普通卡组抽不回退全局。奖励继续使用 fcg_add_card，满 7 张转印花。
- 新行程记录实际入场费 entry_cost，用于跨请求结算收据；已有旧行程仍按已付 500
  展示费用，未领取奖励使用新档位，不追溯重发已领取奖励。

实现
- include/fcg/draft.php 新增 fcg_draft_tiers 静态表，入场与领奖共用。
- presentation.php 将同一张表放入页面数据；fcg.js 据此显示价格、禁用门槛及结算数量，
  并说明保底回退与实际入场费用。更新模板的 JS 版本号。
- gamedata/fcg_shop.php 的表象补充包、深潜重构包添加 rare=false，同步说明文案。
  核心残响、Vol.2 专属包与印花兑换规则不变。
- 核对源码发现通用商店池原本包含能量卡。上述两包修正后各 82 张（70 张非能量卡
  +12 张能量卡），核心残响 66 张。交接稿的 70 是剔除能量后的数目；本次只按要求
  修正商店的稀有混入，远征保底另行过滤能量，未修改所有卡包的通用规则。

已有站点的商店同步

  （原 item_id=8），核对类型均为 fcg_pack，再在原 reward_payload 中加入 rare:false。

  表象：{"upgraded":false,"rare":false}
  深潜：{"upgraded":true,"rare":false}

  和「非稀有已升级卡随机一张」。本次未操作生产数据库。
