FCG 牌桌第四、第五轮界面优化
依据 fcg_tabletop_ui_round4_handoff.md、fcg_tabletop_ui_round5_handoff.md；冲突以 Round5 为准，基于 nouveau / 1fae3dd。

改动
- 己方生命、头像、状态和能量移至帮手右侧，操作按钮在信息下方。宽桌面保留 64% 手牌列；701–900px 按方案收窄手牌；手机保持信息、操作、帮手、手牌的竖排顺序。
- 头像攻防角标放大为 48px、数字 28px；窄屏用 42px / 24px。帮手角标字号 22px，底层剑盾放大至 2.2em、透明度 .6；攻击红 #ff6b5e、防御蓝 #6ba5ff。
- 构筑、手牌、检视、详情、经典帮手的属性行复用 cardStats()：防御统一为盾牌，攻防同色，卡面生命 #c65b4e。牌桌帮手生命与玩家血球均为 #fff2db。
- 详情、检视的费用改为 fcg-cost 的行内圆徽章，保留色彩描边及辅助说明。
- 双方牌库和对手手牌复用 tableCount() / fcg-tbl-count-badge；对手手牌使用 CSS 牌背加手掌，计数数字白色。保留己方 .fcg-tbl-deck 与对手 data-foe-deck 动画锚点。
- 帮手冻结、潜伏改为卡面上方的 statBadge() 状态球；冻结显示红色 -N，潜伏显示红色“潜”，完整含义在说明中。可呈现 payload 中的负 regen、非零 barrier/vuln；无状态不生成空行。
- 按 Round5 不新增稀有/升级标记。两处静态资源版本直接更新至最终 20261027t6。

实现细节与服务端核对
- CSS Grid 同格元素不会按 DOM 顺序自然上下排列，因此用明确的两行分别放置信息、操作；帮手和手牌跨这两行，避免按钮覆盖信息。
- 701–1280px 的己方信息采用紧凑头像及纵排状态，避免内容挤入手牌；小血球的数字和上限文字同步缩小。手牌左侧留出放大余量，避免 1.3 倍悬停覆盖信息。
- engine.php 的 frozen/stealth 属于帮手；中毒、符盾、破绽当前修改玩家 sides 字段，帮手召唤及结算没有这三个状态。account.php / social.php 的公开响应保留 monster 对象。因此没有需要补传的现有帮手状态，也没有改服务端、存档或规则。
- 修改仅涉及 include/fcg/fcg.js、include/fcg/fcg.css、templates/default/fcg.htm，以及本记录。
