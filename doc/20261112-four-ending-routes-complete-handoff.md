## 2. 伪·解禁路线实装规格

### 2.1 召唤与 NPC 配置
* **普通红暮掉落**：`gamedata/cache/npc_1.php` 中 type 1 sub 0 普通红暮，死亡必掉 `挑战者之印` 与 `红杀教头挑战状`。
* **召唤处理**（`include/game/item.npc.php`）：
  * 使用 `挑战者之印` 时，调用 `addnpc(7, 3, 1); addnpc(7, 4, 1); addnpc(7, 5, 1);`，一次性召唤朱鹮三人组：
    * `type 7 sub 3`: FP-T0KI「HOROU」（破虹反弹 + 换装 6 符卡武器库）。
    * `type 7 sub 4`: FP-TOK1「ORIHIME」（解放双倍攻防 + 飞行不耗 SP）。
    * `type 7 sub 5`: FP-TO2I「SAYA」（来潮真伤 + 勇谍锁血 200）。
  * 掉落：三人各自必掉 `社员专用的ID卡`。
  * 合成：3 张 ID 卡合成 `解除钥匙`（`itmsk` 保持 `'v'`）。

### 2.2 Xharmer 支线任务与化身平台（`npcplatform`）
* **触发机制**：
  * 地点：玩家在「指挥中心」探索（`search.func.php`）时判定。
  * 限制：每个角色每局游戏仅限触发一次（记录 `$data['clbpara']['xharmer_event'] = 1`）。
  * 概率：当进入指挥中心探索时，若未触发过，掷骰 25% 概率触发对话弹窗（`mode=dialogue`, 对话键 `'xharmer_meet'`）。
* **选择与奖励**：
  * 玩家选择「接受」：直接向玩家背包放入一件 `npcplatform` 物品（若背包满则掉落至 `itm0`）；选择「拒绝」：无事发生。
  * 任务发完道具即算完成，用不用由玩家决定。
* **平台参数初始化**：
  * 物品名：`便携式化身平台`（种类 `Y`，耐久 1）。
  * 角色决定：根据玩家建卡时生成的 `$data['clbpara']['randver1'] % 3`：
    * `0` => FP-T0KI「HOROU」
    * `1` => FP-TOK1「ORIHIME」
    * `2` => FP-TO2I「SAYA」
  * 变身时效：基于 `$data['clbpara']['randver2']` 映射为 **40 ~ 60 次有效行动**（在 `item.platform.php` 的 `platform_tick` 中按行动消耗）。
  * 还原：时效耗尽或手动脱离时，调用 `restorePlayerOriginalData` 完整恢复玩家原有数据。

## 4. 七日送行 QUEST 与大排档系统

### 4.1 任务接取与流转
1. **获取启动道具**：商店出售或随机掉落 `【动物团的七封请柬】`（种类 `ticket`）。
2. **激活任务**：使用请柬，向玩家的 `clbpara['quest']['sendo']` 同时激活 Q1~Q7 七个任务。
3. **完成与交接**：
   * 前往表侧新地点「代码洪流」（取代表侧 34）。
   * 点击特殊命令按钮「进入动物大排档」，弹出交接界面。
   * 系统核对 Q1~Q7 完成状态：若全部完成，发放解离通行道具 `【湾城通票】`。
4. **重置补做机制**：若某任务因被抢怪或失误完成了“暴力分支”（未得温柔 flag），在动物大排档界面点击「重置任务」，对应任务状态重置为待完成，允许在下一个 180 秒事件周期重新挑战。

### 4.2 七大公共事件规格表

## 5. 湾城投影隐藏地图组与生存环境

### 5.1 地图定义与隔离
* 采用独立物理地点 ID（如 `pls 120~129`），录入 `$hplsinfo`，使用湾城投影专用地图名：
  `1:中央旧城区(落地点/黑市) | 2:新金融核心区 | 3:西部山区 | 4:港口工业区 | 5:玄武数据公园 | 6:「下层」地下商业街(黑市) | 7:天青大桥 | 8:岚江口生态再造区 | 9:寂山书院(BOSS坐镇) | 10:东洲岛`
* **无禁区**：在 `system.func.php` 禁区推进逻辑中，湾城地点完全免疫禁区侵害。
* **开局零地雷**：初始化时不预埋任何地图陷阱。
* **丰富物资**：各子地图刷新高阶武器、优质弹药、防具及无毒强力补给。

### 5.2 落地福袋与专属黑市商店
* **落地应急福袋**：玩家在「中央旧城区」落地时，直接获得 `旧红杀应急补给包`（打开获得：根据玩家最高熟练度定制的成长武器 + 适配弹药/箭矢 + 基础防具套件 + 强力急救剂）。
* **专属黑市商店**：
  * 地点：**中央旧城区** 与 **「下层」地下商业街**。
  * 机制：在 `command.php:957` 的商店地点检查中加入这两个地点 ID；当玩家身处湾城投影时，商店商品列表切为湾城专属货架（出售顶级火器、冷兵器、解状态药剂、高级爆炸物），供玩家消耗携带的金钱。

### 5.3 个人 75 分钟倒计时与超时判定
* **时间戳**：进入时记录 `$data['clbpara']['dissociation_deadline'] = $now + 4500`。
* **展示**：传统界面状态栏下发剩余秒数，前端 JS 倒计时显示。
* **判定**：玩家每次提交行动时校验 `$now > deadline`，若超时，立即触发以善德/恶德（或终局两柱）名义执行的专属处死死法 `death('dissociation_timeout')`。

## 6. 伪·解离路线实装规格

### 6.1 入场与扒光规则
* **门槛**：使用 `【湾城通票】`，且温柔数在 4~6 项（或虽 7/7 但持有轮椅技能）。
* **扒光**：清空所有装备栏（`wep`, `arb`, `arh`, `ara`, `arf`, `art`）及背包栏（`itm1~6`, `itm0`），保留角色等级、人物基础属性、武器熟练度与已学社团技能。

### 6.2 善德·恶德与动物伙伴战斗
* **驻守分布**：善德（club 13 铁拳无敌）与恶德（club 2 见敌必斩）坐镇「寂山书院」；7 只动物伙伴中随机抽取 4 只分散在其他子地图。
* **技能继承与移除**：善德恶德开局持有“未刷出的 3 只 + 存活的 4 只”动物技能；玩家每击破 1 只动物伙伴，善德恶德身上对应的技能立即被注销移除。
* **善恶德版动物技能 vs 动物本尊微差**：
  * 动物本尊：机制数值激进，偏单体爆发。
  * 善德恶德版：恶化步长稍缓（例如狐火每层 -5% 命中而非 -8%），但因复合多项机制，形成慢性扼杀。
* **七动物恶化机制**（记录在玩家 `clbpara['animal_debuff']`，每次交战递增）：
  1. Blasty（荣誉之拳）：受击 HP 压至 P% 地板，P 每战递增，达 100% 极难生存。
  2. Holly（战意）：受击扣战意，战意耗尽陷入无法搜索状态。
  3. Dante（熬战）：移动/攻击体力成本递增，有效 SP 上限递减。
  4. Akane（关节锁）：依次施加腕锁（降攻）、腿锁（增移动耗）、颈锁（流失SP）。
  5. Sandy（狐火）：玩家命中递减，对方先制递增。
  6. Albert（啮噬）：战斗损耗装备耐久。
  7. Kiko（天运）：受致命伤触发免死判定，概率随交战递增。

### 6.3 主动逃跑恢复数值机制（配置化）
* **规则配置**（`gamedata/cache/dissociation_1.php`）：
  ```php
  $dissociation_cfg['flee_hp_recover'] = 0.25; // 恢复 25% HP
  $dissociation_cfg['flee_sp_recover'] = 0.25; // 恢复 25% SP
  $dissociation_cfg['flee_debuff_reduce_layers'] = 1; // 动物恶化层数回退 1 层 (或20%)
  ```
* **实现**：玩家在与善德或恶德交战中，主动点击「逃跑」并成功脱离时触发，使玩家具备拉扯重整的战术空间。

### 6.4 结算
* 击破善德掉落 `善之印`，击破恶德掉落 `恶之印`。
* 二者合成为 `【解离凭证·幻境】`，使用后调用 `gameover('end7')`，结算伪解离胜者剧情。

## 7. 真·解离路线实装规格

### 7.1 入场与模式ＥＸ（`horizon=2`）
* **门槛**：温柔 7/7 且无轮椅技能。
* **扒光入场**：同 6.1 节。
* **锁定 `horizon=2`**：
