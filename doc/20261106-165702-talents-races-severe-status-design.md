# 账户天赋树 种族与恶性状态策划讨论稿

日期：2026 年 11 月 6 日（UTC）

适用项目：PHPDTS 常磐大逃杀

状态：策划讨论，供其他开发者评阅；本次只新增文档。

玩家通过击败教头、动物团等 NPC 取得账户天赋点，永久收集技能头衔，并用有限点数选择数值强化方向。种族提供不同的身体、装备与资源运用方式；恶性受伤和诅咒则扩展战斗中的限制、反制与准备要求。这些能力可以进入玩家的 PvP 和 PvE 构筑，真解离承担低通关率的终极 PvE 挑战。

以下将内容分为四种状态，避免把讨论建议当成实装要求：

- **作者定案**：作者在本轮明确提出或确认的设计，包括明确接受的鱼人方向。方向已定不代表数值、触发细节已定。
- **作者待议方向**：作者提出、仍在考虑的内容。
- **旧原案**：论坛原帖中的效果及疑问，保留以便继续讨论；本轮明确修订的地方以本轮为准。
- **整理者建议**：助手提出、尚未经作者接受的补充，不作为实施前提。

## 一 作者定案

### 恶性状态的存放与技能来源

恶性受伤和诅咒放在 `clbpara`，不扩写或改变现有 `inf` 的普通伤病表达。具体状态键、参数与保存方式留到实施时沿用现有机制决定。

作者最初将这些恶性机制的 NPC 来源限定为真解禁、真解离 NPC；随后明确，教头和动物团的技能可以通过账户天赋树取得，供玩家用于 PvP 和 PvE。因此不能据此追加“只有 NPC 能使用这些技能”的限制。哪些技能最终包含哪些恶伤、诅咒，以及玩家档参数，仍需逐项确定。

**噩梦本来就是面向玩家对玩家使用的能力**，可以从教头或强力 NPC 身上取得。当前切换灵子视界主要用于早期躲避玩家、挑战种火，所以噩梦未必能显著增强掉落它的后期 NPC；这不影响它作为玩家技能的价值。它在后续对局中的早期使用，与取得来源处于后期并不冲突。

旧原帖中泛指事件、普通物品和陷阱等来源的措辞，不自动构成本轮新增投放范围；应与上述来源和玩家取得途径一起核定。具体 NPC 配对仍属第四节建议。

### 账户天赋树

1. 击败教头、动物团等相应 NPC，获得对应的天赋点。
2. 每个账户的天赋点获得有上限，因此不能取得每条树上的全部数值产出。
3. 树的节点上放置可解锁对应技能的头衔。
4. **节点可以全部解锁，技能头衔可以永久全部收集；有限天赋点限制的是当前数值投入。** 不应把取得全部技能头衔写成必须同时点满所有数值。
5. 取得的技能可以用于 PvP 与 PvE。

尚未确定：点数上限和发放次数、重复击杀如何计入、节点连接与解锁条件、数值奖励内容、点数重新分配规则，以及入场时哪些头衔效果同时生效。“永久持有全部头衔”不自动等于“全部技能同时生效”，本轮也没有确定新的技能槽数量。

种族通过账户天赋树节点解锁，是作者目前考虑的获得方向；尚未确定每个种族对应的节点、前置经历和取得条件，不能将某次任务或击杀自行指定为唯一解锁途径。

### 种族的共同设定

现有种族名单为人类、兽人、妖精、龙、鱼人、ＡＩ。非人种族进入游戏，与虚构层“幻境会具现曾经输入的东西”相衔接；善德、恶德和动物团是相关叙事依据之一。

**头部破坏的免疫名单已经确定：妖精和ＡＩ免疫，其余种族不免疫。** 鱼人另有上下肢破坏免疫。具体如下：

| 种族 | 头部破坏免疫 | 本轮明确的其他恶伤免疫 |
| --- | --- | --- |
| 人类 | 否 | 未指定 |
| 兽人 | 否 | 未指定 |
| 妖精 | 是 | 未指定 |
| 龙 | 否 | 未指定 |
| 鱼人 | 否 | 上肢破坏、下肢破坏 |
| ＡＩ | 是 | 未指定 |

### 兽人

兽人偏稳定防御，对除灵系之外的物理攻击具有高免疫能力，对额外属性较弱，尤其惧怕火焰。“高免疫”的具体减免比例或判定方式尚未确定，不在这里写成完全无伤。

兽人可以将手部装备栏当作足部装备栏使用，反之亦然，因此能够同时装备两件手部装备或两件足部装备，也能正常各装备一件。仍然使用原有两个槽位。

额外技能考虑辅助追击方向，具体技能尚未定案。

### 妖精

妖精为玻璃大炮方向，自身灵系属性攻击加强，但失去自由使用身体防具栏的能力。身体栏永久锁定一件种族装备；作者举例为类似“妖精羽翼”的 50 效果、无限耐久白板装备。**名称和 50 这一数值仍是示例，不作为最终配置。**

每次入场随机选择一个额外属性，该属性的输出与承伤都翻倍。作者进一步确认，随机属性弱点可以体现在这件锁定的身体装备上：以其基础装备数据为底，再承载本局的弱点属性。输出加成是否也由同一装备表达，尚未限定。

额外技能考虑降低消耗方向。灵系强化的具体伤害口径、随机属性池和具体倍率之外的联动尚未确定。

### 龙

龙在作者的设定中侧重商业与工具制造，不采用传统战斗巨龙的默认设计。

- **龙可以直接向系统出售物品，不涉及玩家间交易。** 玩家可将地上、NPC 身上的无用物资转化为金钱，再通过游戏商店取得优势，最大化利用现有商店。
- 探索时更容易发现特殊物品，相应地更难发现常规武器、防具或补给。
- **特殊物品明确指武器、防具、补给之外的东西**，不能擅自改成“稀有装备”或另设收集货币。
- 额外技能考虑加强隐匿方向。

出售价格、是否须先拾取、出售地点或操作方式、任务物等具体物品的可售范围尚未确定。此处没有市场、摆摊、玩家定价等交易系统需求。

### 鱼人

鱼人免疫上肢破坏与下肢破坏。作者已接受围绕**维持行动能力**展开的设计，以及“游走＋滑脱”的方向，不要求地图新增水域。

- **游走**：连续移动时降低后续移动的体力消耗，适合赶路、转移目标和撤离；停下来搜索或交战后结束这一连续移动收益。
- **滑脱**：提高脱离追击或束缚的能力。主动挣脱与提高本次逃脱成功率是待选的具体表达，尚未确定统一解除哪些控制。

具体数值、消耗、触发间隔与控制范围待定。先前提出的“换势”仍为备选建议，未随鱼人方向一并确认为必有技能。

### ＡＩ

ＡＩ此前有新手辅助和一控二乃至一控多两个构想。新手辅助现在已有轮椅技能和乔乔承担，本轮继续讨论本体与分体路线：

1. 将本体安全隐藏在某个区域。
2. 召唤分体，由玩家操作分体进行活动。
3. 分体被击破后，等待一段时间可以重新部署。
4. **本体被击破，玩家立即出局。**

一控二乃至一控多是作者提出的目标方向，具体分体数量、控制切换、自主行动、装备与进度归属、部署代价和附加技能均未确定。第四节提供候选规则，不应提前当成这一原案的限制。

### 真解离的难度定位

真解离是游戏的究极 PvE 路线，默认玩家不应有很高成功率。作者希望以充分发挥的机制型强敌，回应玩家挑战纯数值强敌的能力。

不把“保障较高通关率”“每个种族都同样适应所有关卡”“每战之后必须提供充分恢复窗口”列为本轮要求。是否提供恢复、哪些失误不可逆、各关怎样克制构筑，应服务于这一路线的具体设计。

## 二 作者提出的待议方向

### 普通异常状态升级

另一名开发者曾提出：目标已经处于中毒、烧伤、冻结等状态时，再次被能触发同类状态的攻击命中，可能令异常状态升级，增加更多负面效果。作者将其作为本轮之外可继续发展的额外方向提出，**尚未决定全面实装**。

仍需讨论：

- 它是通用战斗规则，还是特定技能具有的能力。
- 哪些异常可升级、升级几次、增加什么效果。
- 升级依据普通命中、再次致异常成功，还是另一次独立判定。
- 同次攻击、多段攻击能否连续附加并升级。
- 治疗会完全解除、只降一级，还是需要专门手段。

若采用，基础异常可继续使用原有 `inf`，新增加的升级效果放入 `clbpara`。这条承接方式是整理者建议，不表示本轮已经决定升级状态的数据细节。

### 诅咒

原帖整体提出了是否通过休息、物品拔除，以及是否扩充异常状态栏的问题。本轮尚未逐项确定持续时间与解除方式。下表中的“永久”保留原案用语，不擅自解释成跨局或固定时限。

| 诅咒 | 旧原案效果 | 尚待明确 |
| --- | --- | --- |
| 黑暗的诅咒 | 持有者遇敌时永久进入起雾遇敌逻辑 | 是否包含友军误认等全部雾中交互，以及解除方式 |
| 迷惑的诅咒 | 持有者最终命中率永久下降 33% | 原帖询问是否也影响对手；乘 0.67 还是减 33 个百分点未定 |
| 虚弱的诅咒 | 持有者最终伤害永久下降 33% | 原帖询问是否也影响对手；伤害范围未定 |
| 复仇的诅咒 | 对持有者自身无效；击杀持有者的玩家或 NPC，攻击、防御和全熟练随机下降，最高约 10% | 降低比例的取样方式、复活与死亡结算、能否恢复未定；不是把属性降到原来的 10% |
| 背德的诅咒 | 对持有者自身无效；攻击持有者会获得可叠加的背德标记，遭遇负面事件或踩雷时受更重惩罚，随后消耗全部标记 | 叠加单位、上限、命中要求、哪些事件会消耗未定 |
| 断腿的诅咒 | 对持有者自身无效；击杀持有者的玩家获得下肢破坏 | 是否扩大到 NPC 击杀者、触发时机和解除途径未定 |
| 野兽的诅咒 | 持有者处于狂热；攻击或反击时，概率让对手也进入狂热 | 传播概率、狂热与诅咒的解除关系、传播边界未定 |
| 麻烦的诅咒 | RP 自然上升 | 按时间还是行动增长、增长量和除咒后的处理未定 |
| 运灭的诅咒 | 补给效果随机下降；战斗中涉及持有者的数值计算受到随机减益 | 具体计算项、随机范围和抽取频率未定 |

复仇、背德、断腿是惩罚攻击者或击杀者的能力，不应在整理时误写成直接削弱持有者。玩家取得技能已经被允许；是否由玩家继续传播某个具体效果，需要单项定规则，不能预先一律禁止。

## 四 整理者补充建议

本节均为尚未获作者确认的候选。已被接受的鱼人方向已移入第一节；本节不增加新货币、交易市场或实现框架。

### 天赋与种族取得

- 数值节点围绕相应战法安排，例如追击能力、技能消耗、持续时间、恢复间隔，减少每棵树都重复通用面板加成。
- 种族可解释为账号获得“调用已输入幻境的某种入场形态”的资格，再于单局入场选择使用。账号是否永久改变物种、入场能否自由选择尚待作者确认。
- 动物团可以提供兽人形态的叙事线索，但不自动要求七只动物分别成为七种带独立数值的亚种，也不自动赋予兽人全部动物团技能。
- 人类可保留通用、补给与恢复稳定的方向；本轮作者没有确定人类的额外加成。

### 种族交互与附加技能

让已确定的头部破坏免疫实际生效，不建议在同一招上追加等效的“核心破坏”来抵消它。其他攻击伤害仍按相应规则结算；不按种族名称自行推导额外免疫。

| 种族 | 补充建议 |
| --- | --- |
| 兽人 | 对物理分量减伤，对额外属性分量单独结算弱点；互穿装备各占一个原有槽位，同类特殊属性先沿用既有叠加规则。辅助追击可考虑受击后维持追猎、延长接敌机会 |
| 妖精 | 入场立即显示随机属性；双倍先只作用于伤害，不默认连致异常率与持续时间一起翻倍。额外技能可降低灵系技能消耗，或在使用选中属性时返还部分消耗。锁定装备须在换装、夺物等交互中保持种族规则，具体处理待定 |
| 龙 | 让特殊物资的保留、出售、购买常规物资形成资源取舍；隐匿技能服务于携货避战。探索倾向优先调整发现物品的构成，不顺带增加整体物品发现次数 |
| 鱼人 | “换势”可作为后续候选：更换武器或姿态后，下一次行动获得小幅收益。免疫上下肢破坏不默认扩大为免疫全部追击、钢丝和空间封锁 |
| ＡＩ | “快速部署”缩短重新部署等待；“调度”在切换受控身体后降低下一次行动消耗，并限制连续触发；“静默待机”让不主动行动的本体逐渐获得隐匿优势，行动后失去 |

ＡＩ还有以下玩法边界建议，均未定案：

1. 本体可以被发现与击杀，安全来自位置选择和隐藏手段。
2. 装备真实分配给各身体；分体重部署不自动复制损毁前的装备。具体掉落与回收方式另定。
3. 玩家切换受控个体后由其行动，未受控分体是否自主战斗单独设计。
4. 物理伤势属于受伤身体，噩梦等意识类诅咒可跟随控制者；具体状态逐项判断，避免自动将换分体写成万能净化。
5. 真解离期限可归属于参赛者，不因控制切换或重部署重置；本体死亡时全部分体失效。入场位置、资格与其他路线交互尚待讨论。

### 恶性受伤的补完候选

| 状态 | 建议 |
| --- | --- |
| 内出血 | 保留隐藏状态与不逐次报数，但致伤招式留下可识别描述，黑衣能诊断；倾向本效果不直接致死、HP 与上限有下限，上限损失有封顶；治愈后恢复由本伤势扣去的上限 |
| 内脏破裂 | 回复量下降与“解除异常”分开，保留明确的治疗出口；黑衣主动治疗可沿用自愈入口增加专属效果 |
| 下肢破坏 | 以最大 SP 的 80% 为门槛和移动费用，并替代普通移动消耗；辅助装备只绕过影响，脱下后伤势仍在 |
| 上肢破坏 | 禁用物品但允许换装，使辅助身体装备能在受伤后穿戴；若作者选择必须预先穿戴，应将其作为明确的准备要求 |
| 头部破坏 | 用明确的致死效果表达，不依靠上限归零隐含禁止复活。整理者曾建议沿用现有复活规则，但作者尚未采纳；是否禁复活必须单独决定 |
| 狂热 | 优先限制直接恢复 HP/SP 的补给，解除狂热专用品例外；保留其增益带来的主动取舍 |
| 噩梦 | 清楚显示禁止切换的原因和解除条件；区分玩家主动切换与死亡、结局、剧情强制转场 |

### 诅咒的补完候选

| 诅咒 | 建议 |
| --- | --- |
| 黑暗 | 仅对持有者应用迷雾遭遇规则，不改变全场天气；是否误认友军单列 |
| 迷惑 | 最终命中率乘 0.67，只影响持有者；对手是否受影响仍由作者决定 |
| 虚弱 | 输出伤害乘 0.67，主动攻击与反击采用一致口径；陷阱是否包含另列 |
| 复仇 | 确认死亡后向击杀者结算一次，复活成功时不触发；最多约 10% 的降低按原案保留 |
| 背德 | 一次攻击行动最多叠一层并设上限，仅在指定负面事件或陷阱实际产生惩罚时消耗 |
| 断腿 | 确认死亡后向击杀者结算一次，事先明确其后果；种族免疫照常有效 |
| 野兽 | 先解除诅咒再正常解除其维持的狂热；玩家版传播规则单独讨论 |
| 麻烦 | 按有效行动增长 RP，刷新、查看页面、无效指令不增长；除咒后停止增长，已增加的 RP 保留 |
| 运灭 | 明确受影响的计算项与减益下限，一次行动抽一次幅度，避免多个计算阶段无意连乘；不自动扩展到所有奖励和随机过程 |

持续时间曾建议解释为“本局持续到解除”；普通诅咒可考虑专用净化或静养，噩梦保留指定解除条件。上述持续时间和净化规则尚未确认。普通治疗是否能清除恶伤、上限损失是否恢复，也不能靠现有通用清除函数偶然决定。

### 异常升级的候选表达

第一版可先只给每种基础异常一个升级形态，不直接把它们全部变成器官破坏：

| 基础异常 | 升级候选 | 新增后果 |
| --- | --- | --- |
| 中毒 | 深度中毒 | 降低补给回复效率 |
| 烧伤 | 灼蚀 | 进一步降低防御能力 |
| 冻结 | 深度冻结 | 进一步限制移动、逃离或追击 |

优先考虑在“已有基础状态，再次成功通过同类致异常判定”后进行升级判定。普通对应药剂可先将升级状态降回普通，再治疗一次彻底解除；这是治疗成本建议，并非作者定案。同次攻击和多段攻击是否允许连续升级，需要与现有同类伤害修正一起决定。

### 真解离的评议尺度

可以接受低成功率、准备不足导致失败、机制组合造成严重后果，也可以让种族或构筑明显破解个别关卡，再由其他关卡考验其弱点。整理者建议检查玩家能否研究出规则、既定解法是否真正有效，以及失败能否提供再次挑战的信息；不以必须降低难度为出发点。
