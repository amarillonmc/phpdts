FCG 可选牌桌界面（2026-10-27）

玩家体验
按 fcg_tabletop_ui_handoff.md 接入新的三分牌桌。课间按钮右侧新增设置，
可在经典牌桌和新牌桌之间即时切换，偏好仅保存在本浏览器 fcg-ui 中。
未选择、存储被禁用或清空存储时仍默认经典；本次不移除经典界面。

新牌桌将导航和页头收为顶部书签，对局结束自动展开；仅在新牌桌的对战
页隐藏 default Footer / nouveau Footer 与任务栏，离开或切回经典恢复。
牌桌提供双方圆形属性与五色能量徽章、产能箭头、驻场帮手、中央沙漏、
牌库卡背、两侧出牌堆，以及非阻塞的设置、出牌记录和牌桌记事浮窗。
手牌整卡点击出牌，详情和弃牌按钮独立响应；不能打出的牌不高亮，仍可
查看详情及弃牌。支持键盘出牌、悬停检视与减少动态效果偏好。
手机与窄窗口手牌横向滚动，状态刷新时保留滚动位置。

实现范围
include/fcg/fcg.js / fcg.css、templates/default/fcg.htm 实现前端。
沿用原有指令、串行请求、倒计时和结算逻辑，两种界面共用原结算内容。
default 页头缺少 viewport 时，只在新牌桌对战期间临时补充，离开恢复。
templates/default/footer.htm 仅增加 id="footer"。两处资源版本均升为
20261027t1。nouveau 仍回退使用 default 的 FCG 模板。

服务端仅增加展示需要的数据：
- engine.php：双方 played_cards 数组记录入堆卡号；法术出牌入堆，帮手
  阵亡进入所属一方的堆，重生和传火薪柴不入堆。回合结算前清空旧堆，
  本次回合结算阵亡的帮手保留到下一回合开头。驻场及解散不算阵亡。
- presentation.php：下发 combo_min / res_colors 静态摘要供前端判断，
  不下发原始 ops。沿用已有 match JSON 保存，不新增表、依赖或资格条件。
堆最多叠放最后 12 张，记录浮窗显示全部；对手手牌和双方牌库内容仍隐藏。

限制
浏览器检查使用本地模拟接口，没有进行真实数据库、账号登录和双人联网
联调；不能据此宣布 HANDOFF 的线上验收完成。默认仍保持经典牌桌。
部署前已经开始的对局没有旧出牌历史，从更新后的下一次出牌开始记录，
不会根据日志猜测或补造旧卡号。手牌简写在小尺寸下截断，完整内容可用
详情按钮查看。触屏没有悬停检视，使用详情按钮。
