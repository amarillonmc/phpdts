# Nouveau 模板优化与 Dark Aero / Frutiger Ego 界面打磨记录

## 改动原因
1. `index.php` 在 Nouveau 模板下原先使用 `.nv-window` 可最小化窗口，元素可以被底边栏隐藏且一屏无法完整展示，部分字段与 `default/index.htm` 不一致。
2. 顶部 `header.htm` 及各页面的标题（`.title`、`.subtitle`）未像 `default` 模板一样大字居中。
3. 历史提交（`5b391af`）遗留的 `templates/nouveau/slidingpanel.htm` 含未引入 Tailwind 的 `SYSTEM PANEL / ENERGY LEVELS / GAME STATS` 结构；虽在 `d6cd4c9` 从 Git 删除，但在覆盖部署环境或残留编译缓存下仍会渲染在 `game.php` 页底且无法正常收拢。
4. `game.php` 的地图窗口（`#nv-map`）原先仅为静态地点名单，点击地点不能直接移动，且 AJAX 刷新后不会同步更新地图高亮与禁区状态；此外原 `game.htm` 顶部 `<!--{eval ...}-->` 内含花括号导致模板编译器 `parse_template()` 截断报错。
5. `templates/nouveau/profile.htm` 缺少部位伤口点击包扎（`infh/infb/infa/inff`）、16 号社团异常状态点击处理、武器熟练度、技能点、装备与背包属性词条、副武器悬停提示，以及全局 `span[tooltip]` / `span[tooltip2]` 样式。
6. `user.php` 中切换 `templateid == 2`（NOUVEAU）存在 `groupid < 9` 的管理员限制。

## 具体改动
- **`user.php`**：移除 `templateid == 2` 时对 `$udata['groupid'] < 9` 的限制，允许全体注册用户在账户资料中选择并保存 NOUVEAU 界面。
- **`templates/nouveau/index.htm`**：移除窗口最小化与底栏隐藏逻辑，改用固定双栏一屏布局（`.nv-index-stage` / `.nv-index-grid`），完整对齐 `default/index.htm` 的游戏状态、计时器、禁区说明、激活/生存/死亡人数、登录/进入/退出表单、站长留言及房间列表弹窗。
- **`templates/nouveau/header.htm` & `footer.htm` & `css.htm`**：
  - 顶部主标题 `.nv-header-title` 与页面内 `.title`、`.subtitle` 改为大字居中。
  - 修复幻想世界菜单 `<details class="nv-vnworld-menu">` 展开时撑高顶栏的问题，改为悬浮毛玻璃下拉菜单。
  - 在 `css.htm` 中补齐 `span[tooltip]`、`span[tooltip2]`、`button[tooltip]` 悬停提示框及稀有度/特效文字样式（`.gold`、`.spitem`、`.rainbow`、`.minirainbow`、`.glitch1`、`.mtg*`、`.ach_box`、`.glow_buttons` 等）；移除首行 CSS 注释中的 `{template css}` 字样（避免 `parse_template()` 将注释内的 `{template css}` 编译为 `include template('css')` 导致无限递归自包含并引发 HTTP 503）。
  - 新增界面配色面板（`#nv-theme-panel`），支持 6 套预设配色与自定义主色/副光晕色/面板底色，并保存在 `localStorage`。
- **`templates/nouveau/slidingpanel.htm`**：新增正式模板文件，复用 `default/slidingpanel.htm` 的完整功能（任务、充能 1-4、种火管理、电梯/闪光同伴任务集成），并补充 Nouveau 风格与右侧收拢定位样式（`right: -520px` 至 `0px`），覆盖旧环境残留文件。
- **`templates/nouveau/game.htm` & `profile.htm` & `assets/js/panel-bindings.js`**：
  - 修复 `game.htm` 顶部 `{eval ...}` 花括号编译截断问题、`[$xyinfo[$key]]` 正则吞括号问题，以及移除底部引用不存在的 `{template bgm}`（BGM 实际由 `sp_terminal` 承载）。
  - 地图节点 `.nv-map-node` 改为可点击移动按钮（调用 `NouveauPanels.moveTo(plsId)` 提交移动指令），并在每次 AJAX 刷新后根据 `window.shwData` 实时同步当前位置、禁区与即将禁区状态。
  - `profile.htm` 补齐六系熟练度、技能点、部位包扎点击按钮、异常状态点击按钮、装备与背包属性词条、副武器提示，并修正原模板缺失语言键导致的 `!hurt!`、`!none!` 等显示问题。
- **Dark Aero / Frutiger Ego 美学与窗口管理（`nouveau.css`、`windows.css`、`game-panels.css`、`responsive.css`、`window-manager.js`、`nouveau.js`）**：
  - 采用高光半透明毛玻璃标题栏、极光流光背景、立体凝胶按钮与发光状态条，保留全部窗口拖拽、缩放和最小化能力。
  - 紧凑化双列装备/背包格与桌面端默认窗口坐标，避免 `game.php` 初始窗口互相遮挡；修复 `NouveauWindows.resetAll()` 立即清除行内坐标与最小化状态。

## 验证情况
- 运行 `php -d short_open_tag=1 -l user.php` 与 `php -d short_open_tag=1 -l templates/nouveau/templates.lang.php` 通过。
- 调用 `include/template.func.php` 的 `parse_template()` 编译 `templates/nouveau/*.htm` 全部 14 个模板，并对生成的 `gamedata/templates/2_*.tpl.php` 逐一执行 `php -d short_open_tag=1 -l`，全部无语法错误。
- 对 `templates/nouveau/assets/js/*.js` 全部 5 个脚本执行 `node --check`，全部通过。
- 运行 `git diff --check` 检查无空白或格式错误，确认 `templates/default/` 未发生任何改动。

## 已知限制
- 本次验证基于模板编译检查与 PHP/JS 语法校验；实际浏览器的拖拽手感、AJAX 交互细节可在站点连接数据库后通过 `user.php` 切换至 NOUVEAU 界面进一步直观体验。

## English Summary
Polished the `nouveau` template into a Dark Aero / Frutiger Ego desktop interface without touching `templates/default/` or core game mechanics: fixed `index.php` to fit on a single screen without minimizable elements, centered large page headers/titles, restored `slidingpanel.htm` to replace any unstyled legacy `SYSTEM PANEL` markup, made `game.php` map locations clickable to move with live AJAX state sync, restored missing gameplay interactions in `profile.htm` (wound bandaging, weapon proficiencies, item attributes, tooltips), added a live color palette customizer (`NouveauTheme`), and removed the admin-only restriction in `user.php` so all users can select Nouveau.
