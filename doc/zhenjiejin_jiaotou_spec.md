# 真解禁·红杀教头 实施规格（Design Spec）

> 四路线结局体系（伪/真·解禁、伪/真·解离）实施规格。
> 机制侧总结：设定站 .hermes/DTS结局机制总览.md；设定侧：DTS设定总览.md（同目录）。

> 本文档只记录"在哪里改 / 改什么 / 怎么改"，不直接修改源码。
> 八人共用框架 + 逐个教头的机制、技能双档（NPC侧/玩家侧）与数值。
> 状态：v0.1 —— 框架草案 + 铁城·Rook 完整规格（首个样板），其余七人待续。

---

## 0. 总则

- 玩家与NPC是同一 Player 对象（玩家 type=0）。教头机制一律"技能化"：
  一个技能本体 + 两档 svars（NPC档全功率写死在教头配置；玩家档由未来天赋树授予时注入）。
- 结局槽位沿用 end3（锁定解除），伪/真差分靠钥匙 itmsk 后缀 + 结局文本分支 + 成就，与现处理一致。
- 依赖的追击/鏖战系统：2026-06-03 修复后**从未实测启用**（`$chase_obbs=0 / $dfight_obbs=0` 封存中），
  启用前必须先过第 6 节测试计划。铁城设计**不开启全局开关**，只做个人特判。

## 1. 框架（八人共用）

### 1.1 召唤物品
- 物品：`红杀教头挑战状`（Y类，名字可再议）。来源：普通版红暮（type 1，无月之影）掉落，替换/新增现有掉落的
  `【我想要领略真正的红杀之力】` 槽位（该物品退场或留作彩蛋由 Nemo 定）。
- 使用处理：`include/game/item.npc.php` 增分支（`挑战者之印` 同款模式）：
  ```php
  elseif ($itm == '红杀教头挑战状') {
      addnpc(25, 0, 1); // 铁城
      addnpc(25, 1, 1); // 绯刹
      // ... sub 0..7 各1
      addnews($now, 'jiaotou', $name, $nick); // 全场广播
      // 销毁物品
  }
  ```
- 广播文案：`include/news.func.php` 增 `$news == 'jiaotou'` 分支，参考 secphase 写法。

### 1.2 八人随机刷点
- `addnpc_1.php` 的 type 25 base 不设固定 pls（或 pls=99 安全随机）；
  若需"随机但避开禁区"，复用 addnpc 现有位置逻辑（pls 数组随机）。
- 每个 sub 可覆盖自己的 pls（merge 顺序天然支持），默认全部随机。

### 1.3 全灭计数 → 刷真红蓝
- 钩子位置：NPC 击杀判定处（`include/game/achievement.func.php` 的击杀成就处理函数内，
  现武神击杀判定 `$killname=="武神 虚子"` 同款位置）。
- 逻辑：击杀 NPC 后查询 `SELECT COUNT(*) FROM players WHERE type=25 AND hp>0`；
  为 0 时：
  ```php
  addnpc(19, 0, 1); // 真红暮
  addnpc(19, 1, 1); // 真蓝凝
  addnews($now, 'jiaotou_final', $name, $nick); // 广播：无月之影
  ```
  （type 19 现有配置 pls=0 无月之影，无需改位置。）

### 1.4 击杀计数防护
- 八人若被 NPC 互杀/禁区/天气击杀，同样计入全灭判定（查存活数即可，不问死因）。

### 1.5 结局差分与成就
- 钥匙：真红蓝仍掉 `冰炎钥匙·炎/冰`（合成 `游戏解除钥匙`，itmsk 保持 'Zv'）→ 成就101 改造为真解禁线。
- 伪解禁钥匙（朱鹮线）用不同后缀，成就100 改造。
- end3 结局文本分支：`templates/default/end.htm` 的 `winmode==3 && state==6` 区块按钥匙后缀（胜者快照里带 itmsk）
  分流 伪/真 两套文本。若快照不带 itmsk，需在 `system.func.php` 的 winners 落库时补一列或从 pdata 读取。

### 1.6 掉落
- 每人配 1-2 件专属装备 + 可选信物（收藏/成就向）。击杀掉落 = 引擎默认行为，无需新系统。

### 1.7 教头特殊机制的分派模式（重要）

- 统一走 `attr_extra_<type>_<name>` 模式：在 `include/game/revattr.func.php` 定义
  `attr_extra_25_tiecheng`、`attr_extra_25_poshi` 等函数，在 `include/game/revcombat_extra.func.php`
  的战斗准备流程按 `$pa['type']==25 && $pa['name']=='铁城'` 分派（现笼中鸟/蓝凝的写法）。
- 旧式 `combat.func.php` 硬编码（红暮样板）仅作参考；教头一律用新分派。铁城 2.3 节的
  "反击脚本位置"随之更新为 attr_extra_25_tiecheng。

### 2.2 NPC侧机制 A：追击锁定（个人特判）

- 位置：`include/game/revcombat.calc.php` 的 `check_can_chase()`（149行起）。
- 改法：函数开头加特判——若 `$pa` 或 `$pd` 为铁城（type=25 && sub 对应/或持有技能
  `npc_rook_chase`），则强制过判定：
  ```php
  // 铁城特判：持有 npc_rook_chase 的一方必追击/必鏖战
  if (has_npc_skill($pa,'npc_rook_chase') || has_npc_skill($pd,'npc_rook_chase')) {
      $dice = 0; // 恒满足追击/鏖战判定
  }
  ```
  （`has_npc_skill` 若不存在，直接查 `clbpara['skillpara']['npc_rook_chase']`，参照现有
  `check_skill_unlock` 系函数写法。）
- 全局 `$chase_obbs / $dfight_obbs` **保持 0**——只有铁城拥有追击行为，其他 NPC 不受影响。
- 效果链（现成）：追击/鏖战状态 → `escape_from_enemy()` 中逃跑按 `$chase_escape_obbs`(50%) 失败
  → 战斗轮次步进（change_battle_turns）→ 先制率用 `$chase_active_obbs`(50)。

### 2.3 NPC侧机制 B：锁技（反击脚本 + 新状态旗 'l'）

- 反击脚本位置：按 1.7 分派模式，在 `include/game/revattr.func.php` 定义 `attr_extra_25_tiecheng()`，
  由 `revcombat_extra.func.php` 的战斗准备流程调用（红暮的 combat.func.php 硬编码仅作逻辑参考）。
- 招式表（每招独立掷骰，学红暮的 event_dice 模式）：

| 招式 | 概率 | 效果 | 文案基调 |
|---|---|---|---|
| 活体攻城锤 | 高 | 反击 flat 800-1200 + 概率手腕受伤 'a'；攻击者带盾/防御姿态时追加防具耐久破坏（红暮火箭弹同款逻辑） | "重拳带着风声轰来" |
| 擒抱锁技 | 中 | 成功则攻击者获得状态旗 'l'（锁缚），时效 3 回合/90秒 | "铁城一个擒抱把你锁得动弹不得" |
| 铁壁 | 低 | 本回合他受到的伤害大幅减免，下回合他的攻击加成 | "他架起双臂，硬吃了这一下" |

- 新状态旗 'l'（锁缚）：
  1. **注册**：`include/init.func.php` 的 `init_inf_states()`（228行）加 'l' 的显示名与图标位；
     受伤状态文案表（`gamedata/resources_1.php` 的受伤状态相关数组）补一条。
  2. **效果**：`include/game/revbattle.func.php` 的 `escape_from_enemy()`（约339行）加：
     ```php
     if(strpos($inf,'l') !== false) $escape_dice -= 30; // 被锁时逃跑更难
     ```
     （叠加在 pchase/dfight 的 $chase_escape_obbs 判定之上。）
  3. **可选**：`$inf_move_sp`（gamecfg）加 `'l' => N`，移动体力惩罚。
  4. **解除**：时效到期自动解除；治疗类道具/医疗间可清除（在治疗处理处把 'l' 加入可清状态）。

### 2.4 玩家侧技能（双档设计）

- 技能定义：`gamedata/cache/clubskills_1.php` 配置条目（自动模板即可，战斗逻辑钩子单独写）。
- 「锁技·擒抱」主动技：
  - NPC档：脚本直接施加，无成本。
  - 玩家档：战斗中发动，SP 250，命中判定吃躲避；成功 → 目标 'l' 3回合；**每场战斗限 1 次**
    （svars battle-used 旗，参照时效技能参数写法）。
  - PvP平衡：'l' 只锁腿（逃跑）不锁手（目标仍可战斗/用药/反杀）；被锁者用高先制反打或传送类
    道具化解；治疗可清。
- 「追击本能」被动：
  - NPC档：配合 2.2 的特判（= 恒追击）。
  - 玩家档：追击/鏖战状态下先制率 +10（在 calc_active_rate 的 chase 分支读技能加成）。
- 技能-社团重叠规则：与同类社团技能（如锡安 c7 系）取高不叠加——此规则对八人全体生效，
  在玩家档技能描述中写明。

### 2.5 测试计划（必过项）

1. **追击系统回归**（与铁城无关，先做）：
   - 测试服把 `$chase_obbs=50 / $dfight_obbs=50` 打开，验证：action/bid 状态机（dfight/chase/pchase）、
     逃跑失败、断线玩家、NPC 死亡后的状态清理、PvP 不触发。
2. **铁城特判**：单挑、围殴、攻击后逃跑、被反杀、他追杀中被第三方拦截。
3. **'l' 状态旗**：施加/显示/时效解除/治疗清除/逃跑判定/移动惩罚（若启用），并回归所有
   inf 相关函数（get_active_r 等）确认无解析炸裂。

## 4. 灵翼·Bishop（象）——规格

人设：金发青年，十字标志长柄狙击枪，头顶光环饰，千米狙杀，枪械改造大师，冷淡寡言。
棋子规则映射：象 = 田字斜行 + **象不过河**（绝不越界——狙击手坚守阵线）。

**核心洞察：灵翼几乎不需要新代码。** "千米狙杀" = 射程系统（L级射程 + 射程压制 'r' 先制）；
"枪械改造大师" = 换装迷宫（club 98）的现成武器库切换AI；"爆头" = c4_headshot 的现成处决判定
（伤害打掉目标85%以上生命时直接处决）；"象不过河" = 他装备远程武器+射程增益，短程武器打他
天然被他先制——**全是数值，零定制代码**。

**弹种武器库（itm 槽位装 4 把备用枪/弹药，全部 W 类道具）：**
1. 灵翼式穿甲弹（WG）：无视防御属性（ex key 走穿甲），对高防目标用
2. 灵翼式爆裂弹（WD）：范围/爆破属性，对贴脸人群用
3. 灵翼式燃烧弹（WF）：火系+灼伤 inf，对躲闪流用
4. 灵翼式标准弹（WG）：高命中，泛用

换装AI（现成逻辑）会按"射程不低于当前 + 不被你的防具属性克制"自动挑弹——玩家防具堆什么抗性，
他就切什么弹打你，这就是"精确分析弹道"的游戏化表达。

### 4.2 NPC侧机制（全现成，仅数值配置）

1. **射程压制**：L级射程 vs 玩家的 S/M 武器 → 天然先制（'r' 射程属性），近战贴脸先吃一枪。
2. **爆头处决**：c4_headshot（现成：单次伤害 > 目标生命85% 时处决）——打残血的必死。
3. **弹种切换**：club 98 换装AI，每回合概率换弹。
4. **不过河**：rage 150 + 不挂追击技能 → 他永远不追人；你跑了就是跑了，但你下次回来还得吃先制。
5. 可选风味：他开枪时 addnoise 噪声更大（狙击声全图可闻，暴露战场位置，引第三方）——若启用，
   在 `combat.func.php` 的 addnoise 调用处对灵翼加特判。

### 4.3 玩家侧技能（双档）

- 「穿杨·狙杀」主动技（新技能，`clubskills_1.php` 配置 + 战斗钩子）：
  - NPC档：被动常驻（c4 三件套已表达，不需要主动技）。
  - 玩家档：战斗中发动，SP 300 + 武器耐久消耗；本回合先制判定 +30、该次攻击无视目标防御30%、
    若命中且伤害 > 目标当前生命50% → 追加爆头判定（即死小概率）。**开火即暴露**：本场战斗内
    自身防御 -30%、闪避 -20%。每场战斗限 1 次。
  - PvP平衡：一击定胜负的赌博——秒掉血赚，没秒掉就裸奔挨打；对满血目标收益低（50%阈值难触发）。

### 4.4 反制设计

- 满血进场（爆头处决对满血无效）、高防顶先制、用远程/爆系武器与他同射程对轰（'r' 压制失效）。
- 围殴：换装AI每回合只能切一次，多人多系攻击他顾此失彼；他低防，被近身集火就碎。
- 盾系/吸收系防具拖过他的爆发窗口。

## 6. 破石·Knight（马）——规格

   - ≤3：使用失败（"你还没能放下。"）——物品是否消耗：**待定**（建议不消耗）；

   - 7：**真·解离**（扒光+新horizon锁 → Extra NPC轮战 → 旧红杀车轮战 → DIAMOND+OMICRON）。

### 19.2 七日送行：七个QUEST（锚定七动物）

通用结构：每步 = 大逃杀压力（计时/猎手/禁区/广播/PvP可干涉） + 温柔解法（慢/贵/险，flag+1）
+ 暴力捷径（快/省，完成但无flag）。完成判定走 Q 模板。

**Q1 Blasty（加拿大鹅·拳）——「南飞」**
- 意象：鹅群的迁徙——护它们到南方。事件=猎人团猎杀迁徙中的鹅群（普通鹅意象，非动物团本人）。
- 压力：鹅群（保护目标×N，HP低）持续被波次猎杀，限时+首领在远处。
- 温柔：**优先清理波次**，保鹅群全员存活后再解决首领——守护线。零 build 门槛：护鹅靠清怪
  与站位，不涉及任何武器系熟练度（徒手判定已废弃）。flag+1。
- 暴力：无视波次直取首领（快，但波次持续杀鹅，鹅群减员=无flag）。
- 设计点：同场战斗中"优先目标是鹅还是首领"是真实选择，限时压力下温柔=更慢更贵。

**Q2 Dante（獒犬·防御）——「守护之牙」**
- 意象：看门犬站到最后一秒。
- 压力：全场广播「大排档守卫战」+ 倒计时 + 定时波次来袭（其他玩家可趁机来袭，PvP）。
- 温柔：与 Dante 并肩守满倒计时且他存活（protect + starttimes 计时 + 波次计数）。flag+1。
- 暴力：自己杀光袭击者提前结束（无flag——"守护"变成了"杀戮表演"）。

**Q3 Akane（秋田犬·柔术）——「不杀之武」**
- 意象：柔术是"不杀"的武术。
- 压力：恶霸有帮手、会逃窜（限时+追击）。
- 温柔：不击杀——把恶霸HP压低到阈值（≤10%，purify 模板判定）再使用「捕绳」道具擒拿（误杀=无flag）。
- 暴力：直接打死（快，无flag）。

**Q4 Holly（雪兔·远程）——「雪原的目击」**
- 意象：雪兔的白=隐身；远程=狙击。**本步 = 伪解离 Holly「发现率随时间降低」机制的正面预演**。
- 压力：猎手是高躲避目标（hide_r 加成，绯刹式隐身），限时；你找不到=被打冷枪。
- 温柔：用「侦探眼镜」（Q6 clue 模板：定位+降低目标躲避）侦察锁定 → 远程武器精准击破。
- 暴力：把 Holly 当诱饵引出猎手（无flag——利用）。
- 注：本步与绯刹共用 hide_r 技能钩子，实现成本互摊。

**Q5 Sandy（白狐·光线干扰）——「九尾的灯」**
- 意象：狐火与光；干扰=雾（雾=纯叙事，**不改全局天气**——避免"免费天气控制器"滥用）。
- 压力：路线上的「雾影」伏击者（高躲避，复用 Q4/绯刹 hide 机制）+ 护送限时。
- 温柔：每人领取一盏自己的「引路灯」（per-player 任务道具）：持灯时你对雾影的被发现率降低、
  对雾影的发现率提高；持灯从A走到B，抵达交灯。flag+1。
- 暴力：丢灯硬杀穿（无flag——弃灯）。

**Q6 Albert（仓鼠·设备支援）——「吱吱电台」**
- 意象：仓鼠的颊囊=囤积；温柔=分享。
- 压力：限时收集散落全图的「备用电池」×N（可搜索获得、**被杀会掉落**——大逃杀式资源争夺）。
- 温柔：交回全部零件 + **额外上交一件自己的装备**（分享，candy turn-in 模板多件判定）。flag+1。
- 暴力：只交零件不分享（完成，无flag）。

**Q7 Kiko（狍子·极强运）——「鹿跃的终局」**
- 意象：傻狍子的好运；送行仪式。
- 压力：禁区缩圈（禁区结算系统），她被圈在封锁区里。
- 温柔：限时赶到+护送她撤离（protect+时间）→ 抵达后善德·恶德投影现身（quest NPC 对话）→
  接受告别 → flag+1。
- 暴力：没赶上——她凭极强运自己活了下来（你无flag，错过的是温柔本身）。

### 19.3 多玩家并发原则（公共事件架构，重要）

- **NPC 实例全局共享**：每个事件的 NPC 只刷**一批**（gamevars/定时器驱动，静流式事件模板），
  所有开启该 QUEST 的玩家共享同一战场；个人状态（clbpara['quest']）只记录参与与结果，
  **绝不按玩家数复刷波次**。
- **参与判定**（防搭便车）：对该事件 NPC 造成过伤害 / 使用过对应任务道具 / 事件结束时在场
  存活——三者其一计参与，参与才可完成。
- **竞争即内容**：电池（Q6）是世界刷新资源、可争夺；猎人（Q4）被捷足先登就等下一周期；
  恶霸（Q3）先到先捕（周期重刷）。PvP 干涉照旧开放。
- **全局状态零滥用**：不改天气、不刷全图 BUFF；所有"温柔效果"一律 per-player 道具化。

## 20. 七日送行：七事件详细实现规格

> 七事件均为**公共事件**：NPC 全局单实例（gamevars 驱动），非私人副本；玩家状态只记参与/结果。
> 类型分配：type 26 鹅群 / 27 猎人团 / 28 袭击者 / 29 恶霸 / 30 猎手 / 31 雾影 /
> 32 善德·恶德投影 / 33 动物团七人（hub NPC，7 subs）。均为 addnpc 类。

### 20.1 基础设施

- **事件引擎**（新文件 `include/game/quest_sendo.func.php`）：
  - 事件状态机：`gamevars['sendoQ<X>'] = {active, t_start, t_end, cooldown_until, ...}`；
  - 调度钩子：挂在 `aievent.func.php` 流程（静流同款触发率），tick 处理补员/衰减/超时结算；
  - 参与追踪：`clbpara['quest']['sendo']['Q<X>'] = {joined, particip, gentle, done}`；
  - 结算函数：`sendo_settle($qid)` —— 事件结束时批量结算所有参与者的完成/flag。
- **大排档 hub（修正）**：原英灵殿将隐藏为彩蛋地点，由新地点**「代码洪流」**取代——其
  command 做特判「进入大排档」作为七日送行的交 QUEST 结点（领道具/上交电池/进度查询）。
  动物团 type 33 七人驻于该结点，对话走 npc_chat。
- **非 QUEST 玩家可见事件 NPC**（世界事件）——可自由干涉（杀猎人/恶霸/雾影），大逃杀的一部分。
- **开启/判定物品**：itemuse 分支（19.1 流程），开启后 quest 批量激活 + sendo 状态初始化。

### 20.2 Q1 南飞（Blasty·加拿大鹅）

- **刷出**：事件窗口开启（周期调度）→ 鹅群 type 26×5 + 猎人团 type 27×3（每2分钟补1只，上限5）
  + 首领 type 27 sub 0（强面板）同刷于固定路线起点。
- **猎杀衰减**（无需NPC互战）：aievent tick —— 鹅群每 tick 损失 `存活猎人数量 × X` 的HP；
  玩家击杀猎人 → 衰减放缓。
- **结束**：首领死亡 → `sendo_settle`：鹅群存活数==5 → 温柔（flag+1）；<5 → 暴力（完成无flag）。
  首领未被击杀则事件超时解散、无人结算。
- **参与判定**：对猎人/首领造成过伤害。
- **钩子**：aievent（衰减+补员）、combat kill（猎人/首领死亡计数）、sendo_settle。

### 20.3 Q2 守卫战（Dante·獒犬）

- **刷出**：广播「大排档守卫战」→ Dante（type 33 sub 1，临时驻守点）→ 袭击者 type 28 波次

- **钩子**：aievent（波次+超时结算）、combat kill（Dante/袭击者死亡）。

### 20.4 Q3 捕缚（Akane·秋田犬）

- **刷出**：恶霸 type 29×1 于固定 pls；被捕/被杀后 T 分钟重刷。
- **逃窜**：恶霸被攻击后概率移动（attack_result 钩子：dice → 移向相邻随机 pls）。
- **温柔**：攻击结算后恶霸 hp ≤ 10%（阈值判定）→ 对所在地点恶霸使用「捕绳」（Y类，hub领取）
  → 捕获（恶霸退场，非死亡）→ 使用者 flag+1。
- **暴力**：恶霸被击杀 → 击杀者与已参与者完成、无flag。
- **钩子**：attack_result（阈值+逃窜）、itemuse（捕绳）、kill、重刷 timer。

### 20.5 Q4 目击（Holly·雪兔）

- **刷出**：猎手 type 30×1（hide +60，绯刹机制同款）常驻雪原固定点；被杀后 T 分钟重刷。
- **眼镜**：「侦探眼镜」（hub领取，每人1副3次充能）：使用记录于 clbpara；`calc_clbskill_hide_rate`

### 20.6 Q5 灯（Sandy·白狐）

- **判定=行动结算**：每次行动（移动/搜索/战斗/道具）前对比 `$now` 与 deadline，超时→

- **阈值广播**：剩余 15/5/1 分钟时行动钩子触发 addnews 警告；bot tick 兜底 AFK 者
  （到点即死=超时杀挂机党，与"必须速战速决"的设计意图一致）。
- **BOSS 不设独立计时器**（Nemo 定案）：善德·恶德及动物伙伴的机制统一读**现成的解离计时器**

  倒计时归零的"超时杀"即以善德·恶德名义执行的死法（BOSS 风味文案，非通用超时）。
- **不引入限步数**：挂机=零消耗=无限拖延（需墙钟兜底=双资源）；且与扒光后的移动SP成本
  冲突。限步数仅作为未来可选次级资源，默认不做。

## 22. 伪解离战斗机制：善德·恶德与动物伙伴

> 框架（Nemo 定案）：善德·恶德本身无机制；二者持有**相同技能组** = 本局未刷出的3只 +
> 已刷出且未击破的动物伙伴技能。善德主武器=空手，恶德主武器=斩系且隶属对应社团、拥有该
> 社团技能。社团定案（Nemo）：善德=「铁拳无敌」（club 13），恶德=「见敌必斩」（club 2）。击破动物伙伴 → 对应技能从善德恶德身上移除。
> 动物每局7刷4、分散角落；善德恶德坐镇寂山书院。

### 22.1 状态语法（七套机制的公共骨架）

- 状态载体：**玩家 clbpara**（per-player，BOSS全局但恶化按人记账）；
- 递增触发：与该技能持有者（动物 or 善德恶德）**每次交战**（一次战斗遭遇）；
- 移除规则：击破动物 → 技能移除 → 该状态停止恶化（已积累数值随之作废）；
- 终点：状态到阈值 = **击破不可能**（认败或被超时杀）；
- 全部数值（初始值/步长/阈值）进 gamedata 解离配置文件（`dissociation_1.php`），
  **初始值取小**（Nemo 定案），便于调试。

### 22.2 Blasty（加拿大鹅·拳）——「荣誉之拳」（已定案）

- 殴系超重拳，超大倍率；荣誉：不会打死你——把你的HP打到**百分比 P%**（P 存 clbpara）。
- HP ≤ P% 时再被命中 → 她不留手，高概率致死。
- P 随每次交战上升（她的耐心下降）→ P=100% → 必被秒杀，击破不可能。
- 默认：P 初始 30%，每次交战 +10%（config 可调）。
- 钩子：伤害结算（命中后 HP 下限处理）+ 交战计数。

### 22.3 Holly（雪兔·远程）——「战意」（已定案）

- 射系，低伤害；攻击削减你的**战意值**（clbpara，初始100）；你对她的伤害可回升战意，
  但她伤害低，每次被命中净下降。
- 战意归零 → 你再也探索不到她（hide=100% 表达）→ 击破不可能。
- 默认：每次被命中 -5，战意回升 = 你对她的伤害×0.3（config 可调）。
- 钩子：被命中结算 + hide calc（战意=0 → 不可发现）。

### 22.4 Dante（獒犬·防御）——「熬战」（已确认方向）

- 层满 → 你被消耗战钉死（动不了=打不了）→ 击破不可能。
- 在善德恶德身上：拖得越久，你连走到她们面前都走不动。
- 钩子：move/attack 成本判定（search.func.php 消耗处 + 战斗攻击判定）。

### 22.5 Akane（秋田犬·柔术）——「关节锁」（已确认方向）

- 状态：被锁部位（腕→腿→颈），每次交战锁一个新部位（复用铁城 'l' 状态旗基础架构扩展）。

### 22.6 Sandy（白狐·光线干扰）——「狐火」（已确认方向）

### 22.7 Albert（仓鼠·设备支援）——「啮噬」（已确认方向）

  （红暮拆耐久机制现成复用：infrate/inftimes 流程）。

### 22.8 Kiko（狍子·极强运）——「天运」（已确认方向）

### 22.9 合流后的战术含义

七条状态并行恶化，拖久=死法叠加：HP被百分比锁死 / 战意归零找不到人 / 行动力钉死 /
三锁瘫痪 / 雾里打不中 / 装备被拆光 / 对面杀不死。

善德恶德开局技能 = 3（未刷出）+ 存活动物数。

## 23. 真解离视界：模式ＥＸ（horizon=2）规格

> 现状核对（引擎事实）：玩家可**自由切视界**——`command.php:767` 的 `hor<key>` 命令 +
> `templates/default/profile.htm` 下拉框（$horizoninfo 循环渲染）；切视界丢全部视野
> （lost_searchmemory('all')）。平台化身也可投影 horizon 字段。
> 现有效果全为二元 `==1` 特判。`$horizoninfo` 仅 2 条目。

### 23.1 定义（Nemo 定案）

- **horizon=2，暂名「模式ＥＸ」**：真·解离专用视界。
- **进入**：满足真·解离条件（七日送行 7/7）+ 使用真解离物品 → **强制切到 horizon=2**。
- **锁定**：进入后**禁掉切换视界的一切入口与方式**——`hor` 命令特判拒绝、profile 下拉
  禁用/隐藏、平台化身禁用 horizon 字段投影与恢复路径。
- 锁定载体：clbpara 锁旗（如 `clbpara['ex_lock']=1`）+ horizon=2 本身判定。

### 23.2 从 horizon=1 复用项

| 项 | 处理 |
|---|---|
| 遭遇门控（同视界才遭遇） | **必须**，防真解离干扰伪解离。**特判：解离地图组内忽略死斗阶段跨视界例外**（gamestate≥50 的豁免只对主地图有效，否则真伪解离会在死斗期互见） |
| 移动·探索消耗反转（HP/SP） | 做成**可配置项**（config 开关：EX 是否耗 HP） |
| 物品·武器描述层 | 保留；资源层新增 horizon=2 文案组；缺失自动 fallback 回 horizon=0 版本 |
| 雷达 | **不启用**——伪/真解离 BOSS 位置由侧边栏 QUEST 部分指出，除 BOSS 外无其他 NPC |
| 休息回复加成 | 可配置；判定从 type 92（种火）改为 **type 0（其他玩家）**——与玩家同处一点同时休息/治疗即获加成（"共斗"色彩） |
| 其余 | 一律按 horizon==1 式特判处理 |

### 23.3 新增战斗修正：「打人和被打都更疼」

- 新伤害钩子（双向）：EX 视界内战斗，**攻守双方伤害系数上浮**（具体倍率进 config，
  如 双方 ×1.5；或"对他人+对自身受击"分别配置）。
- 位置：伤害结算链（get_damage_p / get_damage_def_p 层，按 pa/pd 的 horizon 判定）。
- 语义：模式ＥＸ里没有防御游戏——互殴的尽头。

### 24.8b 车轮战结构（Nemo 定案）

1. **阶段递进**：检测阶段1（Extra NPCs）全灭 → 立即刷出阶段2（旧红杀八人）；
   八人全灭 → 刷出阶段3（DIAMOND + OMICRON）。
2. **刷出规则**：每次**一次性全部刷出**，但**一个地点只有 1 体 BOSS**——八人各占
   湾城投影的一处地点（10 子地图足够分配），玩家全图猎杀。
3. **可选配置项：阶段加时**——根据阶段1 BOSS 消灭耗时给后续阶段加时，倍率可配置
   （`dissociation_1.php`）。方向建议：**速杀奖励**（省下的时间×倍率 → 加时），
   与"速战速决"的设计意图一致；反向（慢杀怜悯加时）也支持，config 里做方向开关。
4. 阶段2/3 无独立限时——沿用全局解离倒计时（加时=延长玩家 deadline 或缩短之）。

### 24.9 合流总结

- 八人 = 主帧教头的暗黑镜像，机制全部可追溯引擎先例（追击/锁旗/换装/多段hit/maptrap/
  干扰/svars学习/残影落空/抹消/毒层）——零黑魔法，全是"已有系统拧到最凶"。
- 车轮战 + 模式ＥＸ双向增伤：八连战的容错率极低，任何一人的状态没处理好都会滚雪球。
- 玩家版八技能全部可走天赋树（双档：NPC全功率/玩家削范围加成本）。

## 25. 真解离·第三阶段：DIAMOND 与 OMICRON（五柱终局）

> 战场：模式ＥＸ。二人刷点待定（合体同点 or 各占一点）。设计语法定调（Nemo）：
> DIAMOND = 计算命运（否定玩家的**过去**）；OMICRON = 跨维度盗窃（夺走玩家的**现在**）；
> 倒计时 = 未来（她们的存活让玩家的终点变质）。

### 25.1 DIAMOND（Carmen Rogers）——「命运演算」（Nemo 定案）

- **命运记录**：每次被他命中 → 他的 clbpara 记录**该攻击者的全部属性快照**（面板/武器/
  携带物品，字段级快照序列化）。
- **命运否定**：每次受击时判定——受击来源与既有记录**相似度过高 → 伤害直接无效**
  （黑暗版"同样的招数对圣斗士不能使用两次"；相似度阈值进 config）。
- **命运反噬**：他攻击玩家时，若玩家数据吻合他的受击记录 → 最终伤害结算后**附加真实伤害**，
  且该玩家攻击他的次数越多，附加真伤越高。
- 反制：多人换人打（记录追不上）/ 多种武器轮流换（但真伤DEBUFF仍会累积）。
- 引擎：受击记录=clbpara 快照；相似度=字段比对函数（config 权重）；伤害无效=伤害结算
  归零判定；真伤附加=最终伤害结算链后追加（get_fix_damage 层）。

### 25.2 OMICRON——「跨维度窃盗」（三支柱+终局开关）

1. **「夺物」**：每次被她命中 → 偷走你一件装备/道具存入她的"维度仓库"（她的 clbpara），
  并**当场装备/使用**——你打她，你的武器到她手里，下回合她用你的武器打你。
  **击杀她 → 仓库爆出全部归还**（反制出口）。引擎：字段级搬迁（platform 投影逻辑同款）
  + 她的武器库并入（club 98 换装逻辑可部分复用）。
2. **「预取」**：战斗中你的攻击在命中判定前先过她的**预取骰**：成功 → 你这一回合的
  攻击被她挪用——你不出手，你的攻击伤害成为她下一次反击的加成。与魇凰"夺走你的刀打
  你自己"递进：魇凰让你的攻击转向，OMICRON 让你的攻击**不存在**。
  引擎：攻击准备事件链（revcombat 攻击准备）插预取骰 + 她反击伤害修正。
3. **「换位」**（Nemo 修正版）：战斗结束后几率判定——她与一名持有**维度标记**的玩家
  **互换 pls**。你打完她逃出生天，转身发现自己站在她的巢穴里，而她站在你刚才的位置。
  引擎：UPDATE pls 互换（静流式传送同款，双向）；标记存玩家 clbpara。
4. **终局开关（config）**：玩家倒计时归零本就切入"投影消散"死法；新增开关——归零时若
  她仍存活，死亡信息附加**嘲讽文案**（"你的终点，也归我了。"）。

**反制轴**：高躲避（不被打中=不被夺物）、速杀（她死=全归还）、多人轮换（分摊被盗与标记）、
以及——别让她活到倒计时归零。

### 25.3 玩家版技能（天赋树双档）

- DIAMOND →「命运演算」被动：你对同一目标的连续攻击，附加真伤递增（你学会了算它的命运；
  即死/无效类不发放）。
- OMICRON →「顺手牵羊」被动：击杀目标时概率额外掠夺一件掉落（战斗中偷装备对 PvP 太毒，
  降级为击杀掠夺）；「预取」被动：对目标的第一次攻击先制率+。
