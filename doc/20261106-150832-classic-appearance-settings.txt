经典界面字体与配色设置

玩家体验
- 经典页面页底新增可展开的“经典界面 · 字体与配色”。调整即时生效，沿用 nouveau 的浏览器本地保存方式，支持恢复默认。
- 字体提供原版 Fusion Pixel、用户提供的 HZK Pixel 12px、微软雅黑。选用 12px 是为了适合现有紧凑表格；正文、彩色物品名和提示框按 12px 显示，并保留标题等特殊字号。
- 配色提供原电波配色，以及深海蓝、夜松绿、琥珀棕、雾紫、石墨灰五套预设。玩家可自行修改页面背景、面板底色、正文文字、强调色和链接色。
- 新配色将场景图与背景色调和，保留物品、伤害、地图禁区等语义颜色。表头采用面板与强调色混合的深色，避免吞掉灰色熟练度提示。

实现位置
- templates/default/header.htm / footer.htm：接入经典专属 CSS、JS 和页脚控件；不修改 nouveau。
- templates/default/assets/classic.js / classic.css：校验并读取本地设置，应用根元素属性和 CSS 变量。设置区隔离 keyup 冒泡，避免下拉框、按钮触发游戏快捷键；AJAX 新内容无需额外刷新钩子。
- templates/default/css.htm 原为空，补入同一份现有基础样式，使关闭 CSS 缓存时也能正确显示经典界面。
- templates/default/assets/fonts/：仅提取用户字体包的 12px WOFF2，原版权说明随 HZK-README.md 保留。该说明未提供开放许可，且注明字模来源及版权风险；本次未将其标为开源字体。

验证
- PHP 7.4.33：使用真实模板编译器在临时目录生成经典首页、关闭 CSS 缓存的首页、游戏外壳和 nouveau 对照页；15 个编译产物及临时生成脚本语法检查通过，无 PHP 告警进入 HTML。
- Edge 157 / Playwright：六套预设、三种字体及 WOFF2 加载、自定义五色、刷新恢复、一键重置、损坏设置回退、浏览器禁止本地存储、窄屏设置区均通过。
- 检查字体在物品名和 tooltip 的实际字号；检查地图与物品语义颜色未改变；设置控件的字母键不会触发游戏快捷键，离开控件后快捷键仍可用。
- 通过实际 postCmd/XHR 序列化和 showData 处理模拟服务器响应，确认页脚设置不进入游戏指令，更新后的物品、地点背景继续使用所选样式。
- 检查首页及游戏预览截图；nouveau 对照页没有加载经典设置资源。
- node --check 与 git diff --check 通过。临时测试页、编译缓存、截图不加入仓库。

限制
- 使用模板与游戏数据桩进行浏览器验证，未连接真实数据库，未做在线对局联调。
- 设置仅保存在当前浏览器，不跨设备同步；未安装微软雅黑的系统使用系统无衬线字体回退。
